# 前 60 分钟 · 无教程学习曲线（无任务列表 / 无提示箭头 / 无高亮指引）

- **Task ID**：PHASE4-001（交付物 2）｜**阶段**：Phase 4 · 预制作｜**主笔**：design-strategist（文策渊）｜**调度**：主理人（游承峰）
- **状态**：待主理人裁决（文末 3 项）+ 待用户拍板
- **本份要回答**：在没有任务列表、没有提示箭头、没有高亮指引的前提下，玩家如何在前 60 分钟**自己学会玩**。这是本作**风险最高、最容易被忽视**的一环。
- **硬约束（不得违反）**：不显示 urgency 数字及任何可数化替身 · 不入行号/序号/缩进/列表点 · 不自建第二套图标 · 默认不暂停不减速 · 工作板是世界物件 · 信条槽默认关。若某条规定在引导场景下会造成流失，**不绕过**——列入回传由主理人裁。

## §0 引导的时间尺度（一切概率的分母）

| 项 | 值 | 含义 |
|---|---|---|
| `TIME_SCALE` | 60 游戏秒/现实秒 | **1 游戏日 = 24 现实分钟** |
| 前 60 现实分钟 | ≈ **2.5 游戏日** | 恰好完整覆盖 S2「两日可读定律」的两个昼夜周期 |
| 06:00 世界标点 | 每 24 现实分钟一次 | 60 分钟内玩家必然亲历 **2–3 次**（无需提示，周期本身即容错） |
| 出生设定 | **D1 05:30**（距首个 06:00 仅 30 游戏分钟 ≈ 30 现实秒） | 玩家落地即撞上第一个世界标点——这是最强的"误打误撞"杠杆 |
| 版本 | `TIME_SCALE` 不被引导修改；引导**不启用** `SLOW`（裁决 34） | 错过一次可等下一次，**等得起**（24 分钟/日） |

## §1 玩家如何自己发现"读作息"——前三个可被误打误撞发现的世界信号

| 序 | 世界信号（载体） | 它教什么 | 误打误撞的机制 | 发现概率 |
|---|---|---|---|---|
| **①** | **06:00 三连标点**：屋灯次第熄灭 → 门口聚集 → 人群**同时向不同方向**散开（不可关闭通道 #6） | "时间"与"出工" | 出生点定在**社区门口正对方向** + 出生时刻 D1 05:30；灯灭是明度高变（ΔL\* 可测）、散开是运动，**不依赖色相与听觉** | **≈必然（>95%）** |
| **②** | **被踩实的旧径 + 岔口脚印链 + 携带物剪影**（C-3 + C-4） | "路线"与"他在干什么" | 出生点**脚下就是**那条被踩实的旧径（离开社区的唯一陆路）；第一个 NPC 是**背桶的取水员**，行进方向＝水源方向 | **高（~70%）** |
| **③** | **需求气泡 + 他走向的目的地**（C-6 + C-3） | "他缺什么"与"我能抢在他前面" | 靠近任一 NPC ≤30m → 气泡出现（视觉显著）；**跟随他一段路** → 看见他到达某点（水站/公共仓）→ 第一次把"气泡＝需求＝目的地"串起来 | **中（~50%）**（需主动靠近并跟踪） |

**学习阶梯（三块基石 = 位置预测能力的全部零件）**：① 时间锚（C-1）→ ② 岗位与路线（C-2/C-3/C-4）→ ③ 需求与目的地（C-6）。三者**必须按序发现**；②③不会先于①发生，因为"他现在在哪儿"这个问题必须先有"现在是几点"。

**提高"误打误撞"概率的杠杆（全部是空间/时刻布局，无一提示）**

| 信号 | 提高概率的做法 | 不采用的做法 |
|---|---|---|
| ① | 出生朝向对准社区门口；出生时刻压在 06:00 前 30 分钟 | 弹窗"注意人群开始行动" |
| ② | 旧径在出生点正下方；首个 NPC 固定为取水员（背桶剪影在 8–25m 可辨） | 高亮那条路 / 画箭头 |
| ③ | 需求气泡在 30m 内出现；该 NPC 当日路线经过公共仓（玩家跟一趟即闭环） | 标注"他在去取水" |

> **反目标（明写不做）**：不做"新手教程"、不做"高亮当前目标"、不做"按 X 键拾取"的强制教学、不做感叹号 NPC。**理解必须来自玩家自己的归纳**（Core 验收 2 能测到东西的前提，S9 §6.1-3）。

## §2 玩家如何理解"我拿走的东西原本是某个人的"——机制级教学路径（**不能被文字告知**）

**P4 的情绪核心**：一切稀缺最终由某个具体的人承受。教学路径**全部是机制**，零文字提示。

| 步 | 机制（来源） | 玩家看到什么 | 它如何不靠文字地建立因果 |
|---|---|---|---|
| 1 | **归属先于物品暴露**（S1 §1.3①：`claimant` 槽**先于** `items` 解析） | 容器浮出**一个名字 glyph + 「他明天来」**；再凑近才出 items | **时序强制**：玩家在看见"里面有什么"之前，先看见了"这是谁的" |
| 2 | **拿走（不可逆事件）**：`claimToken` → `ZoneMutation` → 次日 `ClaimDisplaced` | 拿走那一刻 items 才出现；世界**不当场报警** | "我拿走了"是唯一动作，因果从这一刻开始记账 |
| 3 | **回访看见人**（`P_FOUND_LOOTED`：抵达 `plannedDay` 目标且容器 `DEPLETED`） | 次日回到原处 → **一个具体的人站在原地**（蹲守 30min，`activity=ALERT`，肉眼可见） | 玩家亲眼看见"他站在他原本要来的地方"，**不需要任何人告诉他** |
| 4 | **需求升级（可视化闭环）** | 该 NPC 的需求气泡 `severity` 从 1→2→3：**运动幅度加大**（呼吸→急跳）；关运动时**静态替身**由「边缘完整→缺口→斜线划裂」承载 | **一个头的泡泡变了**——这就是"你拿走的东西原本流向某人的喉咙" |
| 5 | **世界侧短句（非 HUD）**（S1 §6-5：`needReason` 翻译） | 拾取日志出现「河口的取水口滤芯没了」 | 是**世界说的话**，不是 "+3 零件"的数字 |

> **反目标**：不做"这是某人的东西"的**文字提示**；不做"你伤害了 XX"的 HUD 弹窗。**唯一允许的"说"是世界自己说的话**（needReason 短句 + NPC 行为变化）。这条是 P4 能否成立的分水岭——一旦加了文字提示，玩家记住的是"系统提示"，不是"我干的事"。

## §3 玩家如何理解工作板不是任务列表——尤其"缺口会过期、可被 NPC 自己解决"

| 学习点 | 机制教学（玩家如何自己发现） | 已裁决支撑 |
|---|---|---|
| **无发布者** | 第一次读板：条目主语是**公共仓 / 岗位 / 某人的需求**（"燃料 · 公共仓 · 还差 1.35 升"），板边**没有感叹号 NPC**，没有人问你"办得怎么样" | S7 §6.2-1 |
| **会过期** | `NOTED` 一条 → 次日回板 → 那条**不见了/变成另一件事**，且**没有"任务失败"提示、不扣声望**（`ReputationDelta`=0）。玩家自己发现"昨天想做的，今天已不是同一件事" | S7 §3.3 / §6.2-3 |
| **可被 NPC 自己解决** | 在路上（未到）→ 下一个 `HOURLY_TICK` 那条**被划掉**（转 `RESOLVED{resolvedBy:"NPC"}`，**不静默消失**，保留到次日日切）→ 玩家看见"有人比我先做了"。**`resolvedBy` 不进正式 UI**（不解释是谁做的） | S7 §7-E1 / §6.2-4 |
| **笔记会过期** | 离板 → 笔记顶部**常驻**「记于 D3 06:12」；行程时间显示过去时（「那时往东北 12 分钟」）→ 玩家第一次意识到"我记得的这条可能已经过期了" | S7 §2.2 / S9 §3.2-B |

**强制体验点的排布（让玩家在 60 分钟内必撞上一次"板自己动了"）**

| 时点 | 安排 | 目的 |
|---|---|---|
| D1 | 板是平静的（河谷 FUEL 1.35L > MEDS 0.18 剂 > SEED 0.09 份，**全 urgency 1**） | 玩家大概率**不会立刻去做** |
| D1–D2 | 玩家取走了带 `claimant` 的东西 → 上游 `NeedUnmet`/`RationIssued.shortfall` 变化 | **缺口集合变化** → 板自己变了 |
| D2–D3 | 玩家回板前（或读笔记）发现"我的清单和现在不是一回事" | 自然得出"这不是给我发任务的板" |
| 兜底 | 若玩家仍把板当任务列表（反复回板前"刷新接受"），**不算教学失败**（习惯难改） | 判定标准是"玩家是否**期待并等待一个'完成提示'**" |

## §4 失败教学设计：第一次"搬空某处→某 NPC 出事"的 ≤3 跳归因

**因果链（完全确定性，同 seed 可复现）**

| 跳 | 时间 | 玩家能看到的世界侧证据 | 机制来源 |
|---|---|---|---|
| 1 | 拿走当刻 | 归属标记槽上**写着这个人的名字 + 「他明天来」** | S1 §1.3① |
| 2 | 次日 | 岔口出现**偏离旧径的新脚印**（`REROUTE`）；脚印的**朝向本身就是信息**（指向更危险的区域） | C-7 / S2 §3.5 / accessibility §4.1 |
| 3 | 再一日 | 该 NPC 需求气泡**升级**，或他出现在更高 `hazard` 区域（携带物剪影 + 步频） | C-6 / C-4 |
| 事件 | 出事时 | **次日清晨社区门口贴出名字 + 那个岗位空了一个人**（Part E ⑥）；社区 `safeDays` 下降（可见） | S0 Part E / S3 §3.5 |

**"不觉得随机惩罚"的四条已裁决机制保证**

| # | 机制 | 效果 |
|---|---|---|
| 1 | **确定性**：同 `worldSeed` 逐位可复现（S0 §C3） | 因果可复现，不是随机数 |
| 2 | **预告闸门**：离屏判死须满足"死亡前 ≥1 游戏日已出现可观测趋势"（水=0 持续 ≥6h 或 `rad≥80` 持续 ≥12h）（S0 §B3.3） | **死亡不是突发的** |
| 3 | **信号先于行为**：`installTick ≤ 行为生效 tick 前 ≥6 游戏小时`（C-7 / `G-SIG-LEAD`） | 玩家有反打窗口 |
| 4 | **死亡不扣声望**（Part E ②，硬断言 `ReputationDelta`=0） | 玩家**不会收到"系统判你有罪"的信号**，因果留给他自己认 |

> **道德时刻由玩家自己认出来**：板上**不写"这是你干的"**（S7 §7-E7）；归因链只在 C8 调试面板可见（开发侧举证 ≤3 跳、`UNATTRIBUTED==0`），正式游戏由世界侧证据自己说话。

## §5 前 60 分钟的分段目标

| 现实分钟 | 对应游戏时段 | 应自然学会（动词/通道） | 达成什么（**可观测行为**，不用"感受到"） |
|---|---|---|---|
| **0–15** | D1 05:30–20:30（含首个 06:00） | 移动 + 相机；**读**的物理面（靠近物件得互动提示）；**取**（第一次开容器）；**负**的初感 | ① 走过社区门口那条被踩实的旧径；② 完成 ≥1 次容器取用；③ 见过 ≥1 个 NPC 的**携带物剪影**与 06:00 **散开** |
| **15–35** | D1 20:30–D2 16:30（含首夜宵禁 + 第二次 06:00） | **读时间**（色温 + 标点）；**读人**（同一 NPC 第二次出现＝仪式冗余）；**负**（负重降速）；**易**（看价格牌 / 首次交易） | ① 至少一次**因拿多了而放慢**（`speedMul` 变化被发现）；② 至少**读过一次工作板**；③ 能表现出"某个人每天这个时候在某个地方" |
| **35–60** | D2 16:30–D3 17:30（含第三次 06:00） | **读系统**：把 C-1~C-4 合并成位置预测；发现"我拿走的东西原本是某个人的"；发现"缺口会过期 / 被 NPC 解决" | ① 至少一次**主动回访**某地；② 至少一次**看见世界变化**（脚印 / 柜子被搬 / 灯多了 / 板变了）；③ 能预测 ≥1 个 NPC 的**次日位置**；④ 拥有 **≥2 个自设目标** |

**与 Core 验收的挂钩**：验收 2（2 游戏日后位置预测 ≥70%）的采样落在 **35–60 段**；验收 3（45 分钟 ≥70% 有自设目标、人均 ≥2）正落在 **35–60 窗口**。故本表即"验收 2/3 的前置条件"。

## §6 明确定义"教学失败"与兜底（**不得用提示箭头或任务点**）

**失败现象（可观测，供埋点；非玩家可见）**

| # | 现象 | 判定 |
|---|---|---|
| F1 | **原地翻箱** | 第 15 分钟末位移 <100m 且容器交互 >8 次但类型单一（未离开出生区） |
| F2 | **不看世界** | 第 35 分钟末**从未**进入任一 `observeRadius`（板 / 容器） |
| F3 | **退守菜单** | 频繁开菜单/日志/设置试图找"该做什么"；寻找"任务日志 / 地图标记"菜单 |
| F4 | **不读时间** | 06:00 标点时不在场，且未寻找任何时间信息 |
| F5 | **把板当任务列表** | 反复回板前"刷新接受"，等待完成提示 |
| F6 | **前哨失败** | 第 60 分钟末无法预测任一 NPC 的次日位置（验收 2 前哨） |

**兜底（禁止提示箭头 / 任务点 / 高亮指引 / 弹窗教程 / 感叹号 NPC）**

| 兜底手段 | 做法 | 它为什么不是"提示" |
|---|---|---|
| 加强已有通道冗余 | 不新增"提示"，只加**一个非色相载体**。例：06:00 标点被漏读 → 强化灯灭的方向性（灯影摆动）；需求气泡被漏读 → 提高 `severity` 档 3 的运动幅度 | 是把**已有世界信号**做实，不是给答案（S9 §7-E1 原则） |
| 世界内物理引导 | 出生点在社区门口那条必经旧径上；首个容器在出生点正前方 **4.0m `observeRadius` 内**；首个 NPC 为背桶取水员，必然走向水源方向 | 是**空间布局**，玩家仍需自己看、自己走 |
| "犯错的成功"当教师 | 0–15 分钟必然"犯错一次"（拿了带 `claimant` 的东西）；15–35 分钟必然看见后果（NPC 蹲守 / 气泡升级） | **世界自己回放**，玩家不需被告诉"你错了" |
| 不惩罚停滞 | F1/F2 触发时世界**不惩罚**（底线 Submission 玩法仍可玩）；让 06:00 标点与首 NPC 路线**周期性经过玩家当前位置** | 提升"误打误撞"概率，而非给提示 |
| 无时限 | 引导**不设倒计时**（accessibility T-1） | 与"世界不等人"不冲突：世界照跑，只是不逼你 |
