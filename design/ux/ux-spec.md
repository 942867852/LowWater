## §1 八动词的交互流程（操作层）

| 动词 | 触发条件 | 输入 | 反馈 | 失败表现 | 与其它动词的衔接 |
|---|---|---|---|---|---|
| **读 OBSERVE** | 进入任一物/人的 `observeRadius`；或原地停留跨一个社交块（蹲点） | 相机环视 + 走近 + 潜行键；**无扫描/透视键** | 容器**归属标记槽先于 items**浮出；NPC 出 C-2 岗位名签 / C-4 携带物剪影 / 需求气泡；场景证据（墙面/尸位）自动读入；偷听层（6–16m 几何保真） | 不进半径＝漏读（P3：不提示、不重复、不追踪）；未带光→辨识/测绘 −2；长文本打开**不暂停世界**，可被 `THREAT_NEARBY` 中断 | → 取（看见 claimant 决定抢/让）· → 说（偷听得 CALLBACK 素材）· → 守望（读出哪个岗位空着）· → 站（读出信条与宵禁） |
| **取 SCAVENGE** | 容器可读且玩家在 `observeRadius` 内；NPC 也在抢同一容器（`claimToken`） | `Interact` 单次（焦点＝最近容器）；进打包界面决定拿什么 | 判定前置面板（档位名+数字「苛刻 14」+成功率+`modTotal`）；三段 `rollCheck`；大失败**必有可见后果**（拆坏出血、惊动抬头） | `tryTransfer` 硬拒绝（超载"塞不进去"，**禁止自动丢弃**）；`claimToken` 被拒（priority/plannedDay 前置，字典序仅终局）；大失败→`isDisturbed=true`+声响 | → 负（决定拿什么）· → 易（拿去换）· → 说（你拿了谁的，之后有 CALLBACK）· → 制（拆解副产物） |
| **负 HAUL** | 打包界面（拾取时 / 出发前）；负重 >0 时持续生效 | 打包界面加减物品（**无格子**，只有 kg 与 `speedMul`）；确认出发 | `speedMul` 实时变化 + 预计行程时间 + 是否进 `speedMul<0.70` 潜行惩罚档（三轮非数字）；实际速度 = `1.4×speedMul` | 超载硬拒绝；`speedMul` 落 clamp 下界 0.45 → 体力加速耗尽 → `ActorIncapacitated{EXHAUSTION}`；遇袭载货损失 25% | → 易（跑商几何题）· → 制（材料运回）· → 守望（运配给/顶岗） |
| **制 FABRICATE** | 在工作位/工具位（`<community>.post_<role>`）附近；持有图纸（＝材料清单+难度，非科技树） | 选配方 → 单次判定键 | 判定前置面板；**品质 roll**（能用三天 / 三周）；品质影响耐久与效果 | 缺料置灰**明写缺什么**；大失败→材料损毁/耐久归零 + 可能 `MINOR` 伤 | → 取/负 供材料 · → 制 出工具（`quality>0.6` 给拆解/修理 +2）· → 守望（修好滤水器提产能） |
| **易 BARTER** | 走到交易点（**价格牌是世界物件**）；或对 NPC 发起交易 intent | 选簇与数量（**5 通货簇**；`FOOD` 无价格牌）→ 确认 | 成交价 = `P×气场项×议价项`；落保留价内**直接成交、无骰**；落区间外→破例 roll（幅度→DC 档，明示「破例 12% · 苛刻 14」）；成交后 `priceImpact` 预测（"明天这里的水 +4%"）；价格牌带「今日价 · 明天变」 | 破例失败→不成交 `REFUSED`/`HARD_BARGAIN`；大失败→`BAD_FAITH`+`GossipSeed`；>30% 直接拒绝不掷骰；`safeDays<4` 且簇∈{WATER,FOOD}→**停止卖出**「他们自己也不够了」 | → 说（以货抵诺）· → 站（`MEMBER` 门槛）· → 负（负重与汇差） |
| **说 PERSUADE** | 进 `DIALOGUE_OPEN_RADIUS`；`canOpenDialogue` 通过（alive/距离/activity）；`InteractPrompt{kind:TALK}` | 选 `DialogueOption`（方向+确认）；**会话内视图冻结** | **三类选项一眼可辨**（普通 / `[言辞]` 灰+档位名与数字 / `[你上次替我们守过夜]` 回调）；欠条页**即时**落账；好感由**世界内行为**承担（让路/留门/多给一份），**不由文本** | 不满足→置灰明写缺什么（"需 言辞 3"/"你带着他们的水"）；大失败→NEG 印象/gossip/对方叫人（`safety −8`）；离开半径或死亡→`ABORTED`，`pendingEffects` 丢弃，未闭合段落**不算说过** | → 守望（承诺 `SERVICE` ＝顶岗入口）· → 易（以物抵诺）· → 站（信条仪式邀请） |
| **站 ALIGN** | 完成准入前置（R≥门槛 + 仪式材料）→ 发起仪式请求；`RitualScheduled` 提前 ≥1 日（**门口挂牌 + NPC 亲口告知**） | 完成**具体仪式动作**（河谷 `share_dusk`：日落前往公共仓倒 ≥1.0 FOOD + 当众分给 3 人；井窖 `water_weigh`：交超额水过秤封存 + 连续守夜 480min） | `tier↑`；`R_A +TIER_GAIN`，`R_B −12×TIER_W`（HUD「明日生效 −24」）；**信条槽在 ALIGN 完成后才开**（默认关） | 中途违反信条→`CreedViolated`→重扣+`creed_breaker` 印象；未完成仪式＝未加入；跨档限速（任一单次日切 `|Δband|≤1`） | → 说（`CREED` 类选项开放）· → 易（`MEMBER` 门槛）· → 守望（接纳度回报） |
| **守望 TEND** | 读板 `POST` 型条目「那个位置今晚空着」+ 时段档；或 S4 承诺 `SERVICE` 类；或河谷信条卡 3 留宿义务 | 在时段档内站在 `Post.locationId`（`POST_RADIUS` 内）并做出 TEND 动作 | S2 判 `completeFactor=1` → 次日 `PostRoster` 多一个名字；**无勾选框、无完成提示**；回报走 S5 `TEND_REP_DAILY`（+3/+1/0）与 S3 配给，**S9 不显示数字** | 离岗 >`POST_ABANDON_MIN`(10min)→`BREACHED/NO_SHOW`；因 `CRITICAL_NEED` 中断→`BREACHED/NO_STOCK` 但 `delta×0.5` | → 说（守完夜**次日**他才会提那晚——记忆生效时间）· → 易（配给）· → 取（顶岗顺手） |

> **所有动词的公共取消方式**：移动永远可用（世界不暂停）；单次交互可被"后退"取消**仅在其未入队前**；`Interact` 入队后下一个 `SIM_TICK` 执行，**入队即不可撤**（见 §4）。**无 QTE / 无连打 / 无按住蓄力**（accessibility C-3/C-7）。

## §3 关键界面流程

### §3.1 工作板 → 随身笔记

| 项 | 规则 |
|---|---|
| 可读条件 | 进 `observeRadius` 才可读（**无 Tab 全图面板**，裁决 5） |
| 板头 | 1 个数字（`safeDays`）+ 趋势箭头 |
| 条目 | ≤3，按 `sortKey` 序（**顺序可接受**）；**无行号/序号/缩进/列表点** |
| 每条构成 | 介质（承载 urgency）+ 一句话 + 语言标签（还行/明天紧/今天就要/有人在挨/已经在死）+ 地名·八方位·时间档 + `haulFit` |
| 控件 | **无"接受"控件** |
| 离板 | → `BoardNote{frozen, frozenAt}`；顶部**常驻** `frozenAt`；行程时间与 `state` 显示**过去时**（「记于 D3 06:12 · 那时往东北 12 分钟」） |
| 刷新 | 进**任一**板前整体刷新；**不提供自动刷新** |
| 空板 | 「今天他们自己够了」+ `safeDays` 与 `trendDelta7d`（**不是 bug，是世界在好转**） |
| `NOTED` | 纯本地标记（进存档，不写世界）；唯一作用是解锁 E1「路上消失」通知与转介 |

### §3.2 欠条页

| 项 | 规则 |
|---|---|
| 位置 | HUD 常驻角标 ≤3 |
| 每条 | **6 字段**（谁 / 什么 / 多少 / 哪天 / 还差多少 / 冻结在哪） |
| 到期前一日 | `deadlineDay−1` **转红** + 三选项入口（补交 / 以工抵债 / 求宽限）；**不弹"任务失败"** |
| 时效 | **即时反映账本事实**（`PromiseMade` 落账即写，不等日切）——补偿 S4 的 D+2 延迟（裁决 C-29） |

### §3.3 对话（三类选项的视觉区分）

| 选项类 | 呈现 | 不满足时 |
|---|---|---|
| 普通 | 默认字色 | 置灰 + 明写缺什么 |
| 技能实显 | `[言辞] …` + 灰字 + **档位名与数字**（「苛刻 14」） | 置灰 + "需 言辞 3" |
| 回调（CALLBACK） | `[你上次替我们守过夜] …`；首次达成为可见 | 同 `tagId` 已用过→置灰明写"你跟他说过那晚了" |
| 名签 | `homePost` 形状 glyph + 名字 + 固定侧位；**颜色不作唯一判据**（glyph/字重/侧位三重） | — |
| 纪律 | 会话内视图冻结；**不解释 effect，只回传 `optionId`** | — |

### §3.4 交易议价

| 项 | 规则 |
|---|---|
| 价格牌 | 世界物件，显示 `base/buy/sell` + 「今日价 · 明天变」 |
| 常态 | 算完落保留价内→**直接成交，不掷骰** |
| 破例 | 显示幅度与 DC 档，**玩家自选是否压价**；>30% 不发起掷骰 |
| 成交后 | 显示 `priceImpact` **预测**（只预测不改价，读 `DaySnapshot[D-1]`） |
| 硬约束 | **`FOOD` 无价格牌**；**瓶盖无支付入口**（实现层断言） |

### §3.5 睡觉 / 等待（含中断规则）

| 项 | 规则 |
|---|---|
| `WAIT` | 30 游戏分钟步进，上限 6h，**正常 SIM_TICK（真实流逝，非跳过）** |
| `SLEEP` | 4/6/8 游戏小时，上限 8h，**快进批处理**（chunk=60min） |
| 中断规则三条 | `THREAT_NEARBY` · `CRITICAL_NEED`（water=0 或 food=0）· `COMMUNITY_ALARM`（**强制退出，已过时间不回滚**） |
| 醒来摘要 | ≤5 条，全部**可点开看归因链** |
| 流速 | **默认不暂停、不减速**（裁决 34）；`SLOW` 仅 Basic/Comprehensive 档、默认关，开启后存档标记「非标准时间流速」（**在读档界面显示，不在 HUD**） |

### §3.6 仓库与公共仓

| 项 | 规则 |
|---|---|
| 形态 | 公共仓是**世界物件**（`stock.<cid>.public`）；写入**只经 `tryTransfer`**（全有或全无） |
| 玩家可见 | `stock` 读数 + **已许诺标记**；社区仪表旁注**木桶短板**是哪一项（"卡在食物"/"卡在水"） |
| 冻结即反馈 | `reserved=true` 的许诺，点下去那一刻**公共仓读数就掉、价格牌就动**（代价前置） |

## §4 误操作与撤销

| 类别 | 动作 | 可逆性 | 减挫设计 |
|---|---|---|---|
| **纯本地** | `BoardNote` NOTED/UNNOTED · 相机/UI 设置 · 打包界面加减物品（出发前）· 对话选项浏览 | **完全可逆** | 不写世界；`hold→toggle`（C-2）；输入缓冲 ≥250ms（C-4） |
| **决策前置** | 判定发起前的成功率面板 · 破例幅度预览 · 行程时间预览 | 可逆（未确认＝未发生） | 玩家**自选难度**（拿多少/走哪条/是否压价） |
| **不可逆（P3 要求）** | `claimToken` 取用入队后 · `tryTransfer` 成功 · `PromiseMade` · 信条仪式完成 · NPC 死亡 · `isDisturbed` 痕迹 · `SET_TRAP` 装机 | **不可逆** | ①入队前可取消；②承诺有三个可执行**代偿动作**（非"任务失败"）；③站队代价**跨档限速 `BAND_STEP_MAX=1`**，拆两日＋`RitualScheduled` 提前 ≥1 日；④`WorldSignal` **提前 ≥6 游戏小时**（反打窗口）；⑤**泄压阀**（黑市/TEND/BARTER/PERSUADE 永远保留）；⑥死亡**必有预告**（`B3.3` 预告闸门：水=0 持续 ≥6h 或 `rad≥80` 持续 ≥12h） |

> **原则**：**"减少挫败"只允许发生在"决策之前"或"后果之后"，绝不发生在"后果之中"。** 任何"撤销一个已入队的不可逆结果"的设计一律违反 P3。

## §5 存档 UX（固定种子与确定性重放）

| 项 | 设计 | 不泄漏的原则 |
|---|---|---|
| 世界印记 | 存档槽显示一张**由世界自己产出的底片**（seed 派生的静态形状/地名/手绘记号），不用数字 | **不显示 `worldSeed` / `simSchemaVersion` / hash** |
| "这是同一世界"的证据 | 存档槽显示**玩家已见的** `safeDays` 趋势箭头 + 同一个 NPC 的固定台词片段 + 玩家画的地图记号 | 只显示 `ViewSnapshot` 内**世界内物件**的观感量 |
| 重放框架 | `ReplayRecord{worldSeed, gameVersion, simSchemaVersion, inputs[]}` 按 **tick** 打点（非帧） | 重放仅供开发工具；正式 UI 不解锁重放面板 |
| 流速标记 | `SLOW` 存档显示「非标准时间流速」（`accessibilitySlow`） | **在存档界面，不在 HUD**（裁决 34） |
| 自动存档 | 密度可调 + 退出即存（`T-4`） | 不提示"已自动存档"的弹窗 |
| **禁止** | urgency 数字 / 归因链 / `DebugSnapshot` / RNG / `pressure` / 甘特图 ——**一律不进正式 UI**（`--assert-dev-ui-excluded`） | — |

## §6 输入方案（原则与冲突处理）

| 原则 | 内容 |
|---|---|
| 一输入一语义 | 不绑定"模式"（无瞄准特写 / 无第一人称切换，概念 §七-1） |
| 单键单焦点 | `Interact` 只锁定最近可交互物，**不循环切换目标**——防误触 |
| 无时机挑战 | 无 `hold` 蓄力 / 无 QTE / 无连打 / 无精确时机（C-3/C-7）；`hold→toggle` 可切（C-2） |
| 相机独立 | 距离/FOV/灵敏度/反转可调；摇晃可关（C-6） |
| 输入容错 | 输入缓冲 ≥250ms 与判定容错（C-4） |
| 可重映射 | 全键位重映射 + 单手预设（C-1） |
| 世界优先 | 歧义时**不吞输入**（玩家可被世界影响）；菜单/对话打开时 `MenuAction` 优先于 `Interact`，但**不优先于 `MoveIntent`**（世界不暂停） |

**冲突处理**
| 场景 | 规则 |
|---|---|
| 容器与 NPC 同在半径内 | 焦点判据：`observed 世界物件 > NPC`；`TALK` 需更近（3m），`TAKE` 在 `observeRadius` 内即可 |
| 长期阅读时按下移动 | 允许（世界照跑）；面板可缩为角落小卡（阅读偏好），不遮画面中心 |
| 对话中按下交互 | 无效（会话锁定），仅"后退/离开半径"可中止 |
| 睡觉/等待 | **只能由明确确认进入**（不可被误触） |
