## 〇、一句话定位

> **这是一个"没有政府、只有邻居"的辐射式开放世界 RPG：唯一的国家已经死透，剩下的只有彼此隔绝、各自有各自规矩的小型自助社区；你的核心技能是翻别人留下的东西，而每一样你搬走的东西，明天早上六点都有某个具体的人要去找它。**

用户强调的"自主日程与行为逻辑的 NPC"，在这里**不是系统卖点，而是整个资源循环的载体**：因为不存在中央权威分配物资，那么"谁每天几点去哪取水、取不到会怎样"这件事本身，就自动构成了本作的经济、叙事与玩家介入支点。反过来说——一旦把 NPC 做成站桩发任务的功能件，自助社区设定就失去了唯一的信息载体，游戏会退化成一个普通辐射 mod。

## 一、方法论路径：动词优先（Verb-First）

先定义玩家能"做"什么，再从动词反推系统、属性与 UI。锁定 8 个核心动词，其余一切皆为服务层：

| 动词 | 英文 | 定义 | 支撑系统 |
|---|---|---|---|
| **读** | OBSERVE | 通过观察（蹲点、看地砖磨损、听对话碎片）推断 NPC 作息与"谁缺什么" | 日程可视化、痕迹高亮、情报日志 |
| **取** | SCAVENGE | 从废墟/容器/尸体提取物资，并与 NPC 抢同一份有限物资 | 区域物资池、归属标记、有限掉落、同时竞争 |
| **负** | HAUL | 在负重/体力/时间三重约束下选择"拿什么、丢什么、运到哪" | 重量量表、体力疲劳、推车与驮兽 |
| **制** | FABRICATE | 用碎片合成工具、滤水器、武器改件、栖身所 | 图纸＝材料清单（非科技树）、品质 roll |
| **易** | BARTER | 在五簇通货的地域汇差中搬运价值 | 无通用货币、社区独立比价、议价 roll |
| **说** | PERSUADE | 用属性/技能/携带物/记忆标签解锁对话分支，或在议事会上改变社区决策 | 记忆驱动对话、契约型承诺、议事会场景 |
| **站** | ALIGN | 接受某社区生存信条并完成代价性仪式，换取准入与配给 | 互斥信条、声望分账、准入仪式 |
| **守望** | TEND | 守夜、分水、埋葬、顶替空缺岗位、护送——"替某社区当一天的人" | 岗位系统、仪式性动词、记忆标签写入 |

**动词 → 属性映射**（保证"轻量 RPG"不浮肿：每个属性只对一个动词簇负责）

- **体魄 VIGOR** → 负 / 守望（负重上限、体力池、伤病抵抗）
- **巧手 HAND** → 取 / 制（开锁、拆解、制作精度、射击稳定性）
- **心智 MIND** → 读 / 制（观察分辨率、搜索判定、终端破解）
- **气场 PRESENCE** → 易 / 说 / 站（议价系数、说服/威慑、社区接纳速度、群体谈判）

> **为什么锁死在 4 个属性**：8 动词 × 4 属性，每个动词都有明确的"我需要练什么"，不存在装饰属性。这是防止认知过载的第一道防线。

## 二、设计支柱（Design Pillars）

**为什么是 4 条而不是 5 条**：第 5 条必然与前四条中的某一条同义反复或与之妥协——而"支柱数量可裁决"本身就是第一次裁决。四条支柱两两冲突，形成张力，每组都给出**裁决顺序**，冲突时不需要开会。

### P1 · 没有救世主，只有邻居（No Saviors, Only Neighbors）

**主张**：任何抽象系统（阵营、声望、市场、危机）必须在**一次短途步行**内落到"某个有名有姓的人、此刻在某个具体位置、想要某个具体的东西"。

**为什么成立**：中央权威的死亡意味着没有任何超地方机构替你兜底叙事、兜底物流、兜底正义。社区规模小 → 每个成员都可被点名、缺了谁都能被看见。这是设定给我们的天赋。

- **支持**：声望按社区独立结算、由具体 NPC 的目击与记忆驱动；社区仪表必须显示**谁**在缺水而不只是"水位 −12%"；任何因果链 ≤3 跳可归因到具体的人。
- **否决**：全局声望条；全揭示的上帝视角地图 UI；"阵营广播"（主城喊一嗓子全图知道）。
- **代价**：放弃大规模战争、国家重建、宏大政治幻想——这是美学排序里 Fantasy 被降级的原因。

### P2 · 看得见的作息（Legible Routine）

**主张**：模拟必须**可读**——NPC 的日程、需求与路线必须在 1–2 个观察周期内被玩家读懂、写进脑内模型，并据此制定计划。读不懂的模拟等于没有模拟。

- **支持**：24 小时循环日程、近乎固定的通勤路线、可视化需求气泡（渴/饿/怕）、仪式冗余（每天同一路口同一句台词）。
- **否决**：纯黑箱效用 AI、随机游走、玩家无法预期的高频抖动、"为了真实感"的随机迟到。
- **代价**：牺牲统计意义上的"真实人性"——我们是非理性的反义词，我们是**可被 metagame 的**。

### P3 · 世界不为你待机（The World Doesn't Wait）

**主张**：后台模拟持续推进，玩家不在场时事情依然发生。**缺位是信息，不是暂停。**

- **支持**：离屏结算、NPC 死亡/迁居不可逆、被盗日记、社区为应对短缺而自行收紧配给。
- **否决**：任务物品永久等你、NPC 无限期悬停在感叹号上、"回来接任务依然有效"。
- **代价**：制造 FOMO 焦虑；对调试与可复现性提出极高要求（见 R1）。

### P4 · 每样东西都有代价，而代价由人来收（Everything Costs; Someone Collects）

**主张**：一切稀缺（负重、水、时间、信任）最终都由一个具体的人或社区承受——你拿走的东西，原本流向某人的喉咙。资源不是"刷新的"，是"从别人的需求链里抽走的"。

- **支持**：有限物资池 + 归属标记（claimant）、脆弱链传导、伤口沉淀、"你把最后一箱净水滤芯拿走了"。
- **否决**：定时刷新的垃圾堆、无限背包、死后无损失的快速重生、全图资源无限再生。
- **代价**：与"不要惩罚探索"的经典 RPG 教条冲突；需要极强的泄压阀（见 D6）。

### 张力矩阵（含裁决顺序）

| 冲突对 | 典型场景 | 裁决规则（冲突时按此执行） |
|---|---|---|
| **P2 可读 ↔ P3 自主** | 越真实的自治 AI 越不可预测，玩家读不懂 | **可读性优先于真实性**。保留"肉眼可验证的规律"，牺牲统计真实。NPC 可以变复杂，但变复杂前必须在世界里有可见信号（加固门锁、改道脚印、议事会公告）。 |
| **P1 邻里尺度 ↔ P4 全局稀缺** | 稀缺冲刷产生全经济涟漪，让系统失去"邻居"尺度 | **所有宏观后果必须 ≤3 跳可归因**。画不成"A 拿走 → B 的管不够 → C 社区少水"，就砍掉这条链条。 |
| **站队互斥 ↔ P3 世界不等人** | 世界推进会让某些门在你还没到时就永久关上 | **关闭必须有预告**：任何永久锁死必须提前 ≥1 游戏日出现可观测趋势（你本来可以看出来并赶过去）。不做无预告的不可逆。 |
| **P4 稀缺 ↔ 探索自由** | 惩罚性稀缺让探索型玩家不敢出门 | **提供泄压阀**：每一次重量级代价都必须同时打开至少一个新选项（更贵但存在的替代路线 / 黑市 / 走私）。 |

> 注：「站队互斥」未升格为第五支柱，而是作为**硬规则**嵌入 P1 + P4 的社群模块（信条互斥：加入 A 会扣 B）。是否升格为 P5，见文末开放问题 2。

## 三、MDA 分析

### 3.1 Mechanics（机制）

**A. 角色系统（轻量）**

- 创建时 10 点分配，范围 1–10：**体魄 / 巧手 / 心智 / 气场**。
- 派生量（玩家能直接看到"我为什么搬不动"）：
  - 负重上限 `= 25 + 5×体魄`（kg）
  - 体力池 `= 60 + 10×体魄`
  - 观察分辨率 `= 4 + 0.6×心智`（米，决定可交互物高亮半径、"能不能看出门锁被人动过"）
  - 议价基准偏移 `= (气场 − 5) × 4%`
- **8 技能（0–5 级）**：拾荒辨识 / 拆解 / 修理 / 野地医护 / 议价 / 言辞（含威慑）/ 潜行 / 测绘。
  - 成长规则：技能条由**实践累积**（做一次涨一点，与物资价值/难度成正比），等级由"实践值 + 对应属性的上限闸门"决定。**没有通用 XP 购买** → 想练议价就必须真去交易，把"练级"和"主循环"焊死。
- **统一判定式**（全游戏只有这一条）：`成功 ⇔ (属性 + 4×技能等级 + d20) ≥ DC`；DC 四档：10 平凡 / 14 苛刻 / 18 危险 / 22 致命。

**B. 稀缺与生理**

- 四项生理资源：**水（时 −8）、食物（时 −4）、睡眠（时 −5）、辐照（区域累积）**；伤病四类：轻伤/感染/骨折/辐照病，各自需要**具体物资**而非通用血包。
- 负重 → 移动速度：`速度倍率 = clamp(1.15 − 0.5 × (当前负重/负重上限)², 0.45, 1.15)`
  → 平方项让"再塞一件"越接近上限痛感越强。这是核心决策旋钮，也是唯一的"难度设置"。

**C. 拾荒（主循环核心）**

- **永不刷新的区域物资池**：每个容器生成时带价值等级（普通/稀缺/关键）与 **claimant**（明天谁会来取它）。某些关键件整张地图只存在一件。
- 发现判定：**见 `systems/01-scarcity-loop.md`（S1）§3.1 的三段 `rollCheck`**（发现 `MIND/scavenge_eye` → 拆取 `HAND/dismantle` → 不留痕 `VIGOR/stealth`，DC 一律取 S0 §D 四档常量）。
  > **裁决 C-02（已拍板 · 本行为回填修订）**：本文档原写的概率式 `P(发现高价值件) = clamp(0.05 + 0.06×(拾荒辨识 − 区域难度) + 0.02×心智, 0.01, 0.60)` **已废止**。理由：它是一条不经过 `rollCheck` 的**第二套骰子**，违反 S0 附录 B-1，且不可归因、不可复现。**任何 GDD 不得再从本文档抄回该式。**
- 缓慢再生仅限两类：野菜（按季节）、雨水收集（按天气）。其余靠**迁移**（商队带来 / 洪水冲来 / 别的 NPC 搬来）。
- **瓶盖不是货币**：它是怀旧收藏品（可堆积、可送礼给老兵型 NPC 触发专属文本）。这一条专门用于防止"通用硬通货"坍缩掉整个动态经济。

**D. 经济：五簇通货 + 地域汇差（本作最关键的原创机制）**

- 通货簇（`TRADABLE_CLUSTERS`，5 个）：**净水（升）、燃料（升）、弹药（发）、药品（剂）、可育种子（份）**。
  > **裁决 C-17 / C-26（已拍板）**：底座 `ClusterId` 为 **6 键** —— 上述 5 个通货簇 + **`FOOD`（口粮，`tradable = false`，单位 `portion`）**。FOOD **不进** `PriceTable/quote/execTrade`，**只进** `Warehouse.stock`、配给、`SAFE_DAYS` 分子、`reservedByPromise` 与 `ItemSpec.cluster`（可被许诺）。**"五簇通货"的称谓与本节全部经济公式不变。**
- 无通用货币；每个社区对五簇各有进出比价（产能结构不同：河谷社区水多药少，井窖社区相反）。
- 每日价格更新：`P(t+1) = P(t) × (1 + 0.25 × (需求 − 库存)/(库存 + ε))`，clamp 至 `[0.6, 1.8] × 基准`。
- 成交价：`P × [1 + 0.04×(卖家气场 − 买家气场)] × (1 − 0.03×议价等级)`，且必须落在双方保留价区间内才成交。
- 效果：把"跑商"变成**同时负重的几何题**，并在数学上保证套利收益收敛但永不归零（运输成本与风险），玩家永远有事可做。

**E. 制作**

- 图纸 = **材料清单 + 难度**，**不是解锁式科技树**；全作十几个配方，防认知过载。
- `品质 = clamp((3×巧手 + 6×修理等级 + d20 − 图纸难度)/10, 0.4, 1.5)`
  → 品质影响耐久/效果，同一物品能搓出"能用三天"和"能用三周"两个版本。**品质而非数量**是成长感载体。

**F. NPC 自主：三层模型（用户特别强调项）**

| 层 | 名称 | 内容 |
|---|---|---|
| L1 | **需求 Needs** | 六项 0–100：水、食、睡眠、安全、社交、信条践行。固定衰减速率；跌破阈值 → 向 L2 提交需求。 |
| L2 | **调度 Scheduler** | 每日 06:00 由社区分配**岗位**（取水/守夜/巡线/修补/育儿），与个人需求做抢占式优先级调度，产出一条 24h 路线。岗位名额 < 人数 → 有人闲着，闲人有社交行为（gossip 载体）。 |
| L3 | **行为 Behavior** | 行为树处理扰动：暴雨改道、发现被盗、遇袭、发现尸体。决策结果**回写 L1 与 L2**（连续被盗 → 明日改道 / 加岗 / 设陷阱）。 |

- NPC 拥有**个人小库存**，产出先进社区公共仓，按社区信条分配。
- **记忆模型**：短期事件记忆（7 天，权重衰减）+ **长期印象标签 ≤5 条**（"替我守过夜"/"偷过井水"/"说话不算数"）。这 5 条直接作为对话条件变量；上限 5 是为了**让玩家的作为被记住，但不被记住到需要无穷写作**。
  > **裁决 C-24（已拍板 · 存储粒度）**：印象标签**存 12 码细分**（S4 §2.5 的 `tagId`），**只在 gossip 传播时 collapse 到 8 码**（S2 §3.7 的 `claimCode`）。本行举的"偷过井水"与"说话不算数"正是必须保持可区分的两条——若只存 8 码，二者会混为一谈。
- **死亡不可逆**；死亡后岗位空缺，社区产能下降：`实际产出 = 额定产出 × (在岗人数/额定人数)`，跌破 60% 进入**紧缺状态**。
  > **裁决 C-06（已拍板 · 实现式）**：分子由"在岗人数 `onDuty`"改为 **`effHead`**（`effHead = Σ completeFactor`：完成 = 1 / 部分完成（迟到 >30min）= 0.5 / 缺席 = 0），即 `实际产出 = 额定产出 × (effHead / rated)`。**60% 紧缺阈值不变**。本文档此处的原式是同一公式在 `completeFactor ∈ {0,1}` 时的特例；实现口径见 S0 Part E ④ 与 S2 §3.4（二者已保持一致）。
  > **裁决 C-18（已拍板 · 命名）**：此处的"紧缺状态"= **`SCARCE`**（岗位在岗率 < 0.60，产能态）。它与 S3 §3.5 的 **`TIGHT`**（`safeDays` ≤ 5，库存态）是**两个不同的指示量**，禁止合并为一个指示灯。

**G. 社区**

- 每个社区由三要素定义：**信条（Creed）+ 产能（Outputs）+ 缺口（Needs）**。
- 信条是硬规则，例如："外人不得过夜" / "余粮十分之一入公共仓" / "争端由持械者决斗裁断"。违反 → 声望重扣。
- **核心可读仪表：安全天数** = `公共仓（水 + 粮）可支撑人日 ÷ 人口`（单位：天）
  → 玩家唯一真正需要盯的数字，也是 P2 的最高产物：一个不用教学就能懂、会自己变的世界读数。
- **声望（按社区独立）**：`R_c(t+1日) = R_c(t) × 0.97 + Σ 当日事件值`；关键事件写入"社区记得的事"（上限 5 条，不衰减），其余按 0.97 自然淡忘。

**H. 对话（对话树 × 模拟 NPC 的正面耦合方案）**

- 分支条件 = 属性值 + 技能等级 + **记忆标签** + 携带物 + 当前信条冲突状态。
- 三种选项风格并存：常规选项 / `[体魄 7] 直接把门卸了` 等技能实显选项 / 由记忆标签动态生成的**回调选项**（"[你上次替我们守过夜] 那晚的东西还在我家桌上"）。
- **对话即契约**：承诺写入社区账本（承诺人 / 内容 / 期限）。**做不到不是 bug，是内容**——到期触发违约事件 → 声望公式 → NPC 下次对话会提到那件具体的事。这是 R3 的核心解法。
- 保留 **Black Isle 式长文本深度**：至少 1 个"文本密度样板角色"（长自白、可被反驳、有立场），以及终端日志/遗书/旧政权宣传品承载"旧政权如何死的"这条史线。

### 3.2 Dynamics（动态）——本作的真正卖点

每条都标了跳数，以通过 P1 的 ≤3 跳审查。

**D1 · 抽血式级联（Extractive Cascade）——主打动态**

> 玩家搬空某废墟（1 跳）→ 依赖该点的两名 NPC 需求链断裂，"这一趟没打着"（2 跳）→ 明日调度器抬高搜索半径，改道进入更危险的辐射坑（3 跳，可见脚下脚印变化）→ 伤病/死亡概率上升 → 其中一人死于辐射或失踪（不可逆）→ 缺水岗位空缺 → 产能降至 75% → **社区安全天数从 18 天掉到 11 天** → 社区收紧配给并向外部索取（更高物价 / 更苛刻的准入仪式 / 甚至向邻近社区勒索）。

**玩家体感**：你没杀任何人，你只是"捡了点垃圾"。这是本作的情绪核心，也是 P4 的直接兑现。

**D2 · 作息空隙（Schedule Gap）与军备竞赛**

> NPC 日程自然产生"某地点某时段无人看管"的窗口 → 玩家学会蹲点 → 但 NPC 会因连续被盗而**改日程**（加岗、改道、设陷阱、把东西搬进更深的屋子）→ 玩家旧知识失效，必须重新"读"（动词 OBSERVE 重新上线）。

**这是全部设计里最漂亮的一环**：它把 P3 从惩罚变成博弈，并且天然要求为"改日程"提供可见预告信号，从而自动满足 P2。

**D3 · 汇差套利与商路自平衡**

> 五簇通货的地域比价差 + 负重上限 = 天然运输商问题。玩家反复跑同一条线会抹平汇差；但运输风险、伤病、雨雪与季节持续制造新的剩余汇差 → **商路永远值得重算**。同时 NPC 商队也在跑同一批路线 → 玩家可以劫掠、护卫、抢先抵达或与之合伙（Killer 型的合法出口）。

**D4 · Gossip 变形传播：名声先你一步到达**

> NPC 间闲聊是有界传播（fanout ≤3 跳），每次跳转带**失真**："他帮我们取过水" → "他替人卖命" → "他是某社区的人了"。

**效果**：涌现叙事成本压到最低（无需手写脚本），同时产生"澄清误会"这一整类玩家目标；探索型玩家获得追踪传播路径的新内容层。

**D5 · 岗位空降：关联感的机械落点**

> 玩家可以实际站进某个岗位（守一夜、取一趟水、替人埋葬死者），短时提升社区产能与接纳度。这不是任务，而是 **TEND 动词**——它让 SDT 里的"关联 relatedness"第一次有了不是选项对话框的实现方式。

**D6 · 黑市与替代供给：稀缺的泄压阀**

> 社区禁酒/禁药/控枪 → 需求仍在 → 黑市节点自然出现 → 玩家可走私，高收益但违背信条（一次性大额声望惩罚 + 写入长期印象标签）。

**这是 P4 ↔ 探索自由张力的法定出口**：每一次代价都开一扇新的门，玩家永不被真正卡死。

#### 主导策略候选与结构性反制

| 候选主导策略 | 结构性反制 |
|---|---|
| **刷单一高价值区** | 有限物资池 + 不再生 + 迁徙的 claimant + 辐射累积；刷完就没了，没人给你补。 |
| **杀光拿装备** | 死亡不可逆 + 记忆标签 + gossip 传播 → 你将无法在任何社区获得配给；且"人死了，他所依赖的知识也死了"（有些阀门只有他知道怎么开）。**但为 Killer 型保留合法出口**：劫掠商队、社区悬赏、决斗法理社区的规则化 PvE 决斗、挑动两社区敌对渔利。 |
| **万能说服** | 契约型承诺是**物质**约束：说动对方 ≠ 你真的有那三升水。且信条互斥，说服 A 必然得罪 B（这条路走得越远，地图越小）。 |
| **无限负重跑商** | 平方项速度惩罚 + 伤病 + 遇袭损失全部。"贪一次"是可选的高风险策略，而非最优解。 |
| **完全不互动 NPC 的纯单机捡垃圾** | 合法玩法（Submission 美学），但会被 D1 反噬：居民离散，最后没人可以跟你交易。**允许，但不最优**——这正是我们要的。 |

### 3.3 Aesthetics（美学）——主次排序

MDA 八美学，**全序**为：

1. **Discovery（发现）— 主打**：两层——**空间发现**（昼夜错位，同一地点 06:00 与 22:00 完全不同）与**系统发现**（读懂某 NPC 的日路线图；意识到"我可以抢在他前面到水站"）。自主 NPC 的全部价值都在这一层。
2. **Narrative（叙事）— 主打（次席）**：非线性叙事，而是**涌现叙事 + 文本密度**。历史藏在终端与遗物里，当下的故事由 D1/D4 自动演出。
3. **Fellowship（羁绊）— 第三**：无多人，但对**具体的人**的羁绊（替他守夜、埋葬他、记住他缺什么）是唯一能对抗荒土冷感的情感来源，也是 P1 的情感兑现。
4. **Challenge（挑战）— 第四**：不是操作挑战，而是**后勤挑战**——负重、零件、连续配给的算术。
5. **Submission（消遣）— 第五但不可删**："捡垃圾"的底层快感就是 Pastime——节律性、低认知负荷的重复。这是我们留给用户"不想玩也能玩四十分钟"的兜底。
6. **Expression（表达）— 弱**：外观自定义、打扮、拍照模式一律下沉到 Extended/Vision。
7. **Fantasy（幻想）— 刻意矮化**：不提供"救世主/重建文明"的权力幻想；保留低剂量虚构趣味（旧政权宣传海报、末日前的日常遗物、荒诞信条）仅供风味。
8. **Sensation（感官）— 刻意不做**：不做视听奇观驱动。预算不允许，且与"看得见的作息"相冲——华丽特效会淹没玩家本该读到的行为信号。

> **主打组合**：Discovery × Narrative。所有钱与工期优先投给"让玩家看见并读懂系统"的那部分 UI 与内容，而非美术奇观。

### 3.4 动机与受众校准（SDT · 心流 · Bartle）

**自我决定论**

| 需求 | 落地机制（不停留在口号） |
|---|---|
| **自主 Autonomy** | 同一目标至少 4 条解法（偷 / 换 / 服役顶岗 / 说服 / 走私）；站哪边由玩家自己付代价。 |
| **胜任 Competence** | 技能由实践涨 → "我真的做得更好了"而非"我刷满了"。正反馈极易理解：安全天数上升、产出品质从"三天"变成"三周"。 |
| **关联 Relatedness** | 记忆标签 + 长期印象（对话回调）+ TEND 动词 + 具体人的死亡不可逆。关系的货币是很小的人情，不是天赋树的好感度。 |

**心流**：本作难度不是设置项，而是**玩家自持的三个旋钮**——背包重量（走多慢）、是否进入高辐射区（能摸到好东西）、是否押上"说服/潜行"的高风险选项。每局出发前 3 秒，玩家实际在为这一趟自选难度。目标始终清晰（我缺一枚滤芯），反馈始终即时（每开一个容器一次结算），难度带由区域层级（平凡/苛刻/危险/致命）提供连续梯度。

**Bartle 覆盖**

| 类型 | 被什么满足 | 载体 |
|---|---|---|
| **Achiever 成就型** | 不是"数值变强"，而是**项目型成就**：把濒危社区安全天数从 11 拉回 60；把五簇通货都建起通路。 | 注意：Achiever 天然想"刷光全图"，与 P4 冲突 → 成就须改写为**可持续性 KPI**（见开放问题 3）。 |
| **Explorer 探索型** | 昼夜错位地图 + 旧政权史线文本 + NPC 路线本身就是动态地图。 | 同一废墟夜里有人在埋东西，白天只剩下土。 |
| **Socializer 社交型** | gossip 网络、撮合、社区议事会辩论（多 NPC 会谈场景）、记得我的对话回调。 | 无多人，社交对象全是"记得你的人"，承载力有天花板，要有预期。 |
| **Killer 杀手型** | 无 PVP → 规则化出口：劫掠商队、社区悬赏、决斗法理社区的合法 PvE 决斗、挑动两社区敌对渔利。 | 必须被 P4（死亡不可逆 + 记忆传播 + 信条互斥）压住，使其永不是最优解。 |
| **Creator 建造型**（补充） | 窝棚/滤水站建造、据点改造（Extended）；自建社区与自定信条（Vision）。 | 明示其在 MVP 之外。 |

> **验证 vignette（同一天，三种玩家）**：06:10 成就型已经在用 12kg 配额装波形零件；探索型蹲在废车站看那个每天 06:15 来收水的女人今天为什么没来；社交型正在议事会上用"我替你们守过两夜"争取一份配给。**同一个机制底座，三条完全不同的动线。**

## 四、范围分层

### 核心 CORE —— 没有它就不是这个游戏（垂直切片必含）

| # | 内容 | 为什么在这一级 |
|---|---|---|
| C1 | 一张手写区域约 **2×2 km**：2 个自助社区 + 1 个被弃的旧政权设施 + 若干废墟点 | 必须容纳 D1 的三跳链条 → **2 个社区是最小值**（1 个无从体现信条互斥与缺口互补）。 |
| C2 | 4 属性 + 8 技能 + 统一判定式 | 轻量 RPG 的最低可机组成；没属性就无法做长久成长，没技能就无法做实践升级。 |
| C3 | 搜刮 / 负重 / 体力 / 饥渴 / 伤病 / 辐射（最小剂量：辐射区 + 辐照病 + 2 种药） | 主循环的约束全部来自这里；砍掉任一会使 D1 与决策旋钮失效。 |
| C4 | 五簇通货 + 每社区独立比价 + 议价 roll | D3 的燃料；若改成通用货币，跑商与小聚居地的经济叙事塌一半。 |
| C5 | NPC 三层模拟（L1/L2/L3）：**12–16 个有名字 NPC**（2 社区各 6–8），含完整 24h 日程、需求、个人库存、7 天记忆 + 5 条印象标签 | 用户强调项。16 是"能被玩家真正记住每一个"的上限，也正好覆盖两社区全部关键岗位。 |
| C6 | 社区仪表：安全天数 / 产能 / 岗位空缺 | P2 的最高产物；把黑箱模拟翻译成一个数字。 |
| C7 | 记忆驱动对话 + 契约型承诺（写入账本）+ 技能实显选项 + **1 个 Black Isle 式长文本样板角色** | 对话树 × 模拟 NPC 耦合的正面实现；样板角色用于验证文本密度能否成立。 |
| C8 | **NPC 调度可视化调试面板 + 事件归因链导出 + 固定种子确定性重放** | 对 R1 的直接投资，**必须进 Core**。没有它，我们无法迭代任何 NPC 行为。 |
| C9 | **由真实需求生成的工作板**取代任务板 | 权威真空里不存在"任务发布者"，只有"缺口"。这是防止玩家无事可做的唯一正解。 |

**CORE 验收标准（满足全部才算"核心跑通了"）**

1. **三跳连锁可复现**：固定种子 + 脚本化玩家行为（清空 X 区 80% 物资），3 游戏日内必然观测到：某 NPC 需求链指标变化 → 日程改道 → **目标社区安全天数下降 ≥10%**；全过程可在 C8 面板逐跳导出归因链（写不出归因链的链条视为未实现）。
2. **可读性达标**：不给 UI 文字提示，测试者仅看画面游玩 2 个游戏日后，能预测某指定 NPC 在次日 06:00 / 12:00 / 20:00 的位置，**三选三命中率 ≥70%**。
3. **重复感测试通过**：12 名测试玩家无任务指引自由游玩 45 分钟，**≥70% 在第 45 分钟仍有自设目标**，且人均自设目标数 ≥2（自设，非任务列表给的）。
4. **主导策略检查**：单一最优资源路线的 10 日物资净值，**不得超过最优混合路线的 1.25 倍**（固定种子 Bot 对跑测定）。超标即判失败。
5. **性能预算**：目标机型 GTX 1060 6GB / 16GB RAM / SATA SSD，1080p。场内模拟实体 ≤120（full-behavior ≤40，其余 coarse tick），**仿真（非渲染）耗时 ≤6ms/帧**。
6. **可确定性**：同一存档 save/load 后续跑 10 日，安全天数曲线与原固定种子回放**差异 ≤5%**。
7. **契约必然生效**：对话中的承诺若到期未兑现，3 游戏日内**必定**触发可观测负面后果（声望下降 + 某 NPC 后续对话提及该具体事件）。出不来这条，说明耦合没做通。

> **红线**：Core 期间禁止新增任何系统；任何新增功能必须先证明自己能通过验收 1 与 3。

### 扩展 EXTENDED —— 核心循环自证后才做

| 内容 | 为什么在扩展级 |
|---|---|
| 地图扩张至 **4–6 个社区/信条** | 数量堆叠；每条新信条都要新的正反文本与准入仪式，成本线性、收益递减。 |
| 社区议事会（多 NPC 辩论场景） | Socializer 主餐，但依赖 Core 的记忆标签系统已稳定。 |
| NPC 商队与中间人 | D3 的放大器；没有商队，跑商依然成立。 |
| 建造：窝棚 / 滤水站 / 据点升级（Creator 型） | 极受玩家喜爱，但会引入选址/承重/塌方一整套新答案。 |
| 武器改造（模块化改件）与配方树第二层 | 制作深度；Core 只需证明"品质 roll"好玩。 |
| 伤病/医疗深化（感染、断肢、外科） | Y 轴深化，可先被 Core 的两种药扛着。 |
| 天气与季节影响产能 | 会显著复位玩家已有的经济模型，必须放到玩家已理解系统之后。 |
| **语言/方言门槛**（语言技能解锁整段文本） | 极高文本价值 / 低美术成本，但大幅抬高本地化与写作成本。 |
| 商路 fast travel 解锁（运输成本换时间） | 便利设施；过早给会毁掉负重与主循环。 |

**判断准则**：每一项都必须满足——"若核心体验不变，它是否存在都不会破坏 D1"。满足即降级，不满足才升级。

### 愿景 VISION —— 长期 / 理想态，可砍

| 内容 | 为何在愿景级 |
|---|---|
| 跨社区战争与人口迁移潮的**纯涌现**演算（非脚本） | 需要 NPC 具备目标层与冲突求解能力，当前写法不可控。 |
| 人口代际演化：生育/衰老/死亡/岗位继承 | 时间尺度（数年）与 RPG 时间尺度严重冲突，且让"认识每个人"的承诺失效（违反 P1）。 |
| **玩家自建社区 + 自定义信条（Creed DSL）** | 本作主题的**最高形态**（从捡垃圾的人变成定规矩的人），也是最大的范围陷阱：制度设计器本质上等于做一个编辑器。**必须先在 Extended 用静态据点做探针。** |
| 玩家行为驱动的世界史年表（结局时的"你离开之后"） | 依赖前两项，且是一次性的大写作量。 |
| 对外开放的 mod / 剧本编辑器 | 交付后长尾生态；不应占用核心工期。 |

## 五、已知风险与缓解

**R1 · 模拟型 NPC 的可调试性与性能**（最高优先级）
*风险*：行为不可复现 → bug 无法稳定重现；1 个出错就能污染整张地图的经济；tuning 无从下手；随 NPC 数量指数爆炸。
*缓解*：① Core 即投入**确定性固定种子重放 + 调度可视化面板 + 事件归因链导出**（C8）——这是坚持把调试工具放进垂直切片的原因；② 严格 LOD 分层：**≤40 full-behavior，其余 coarse tick（1Hz 统计结算），进入玩家视野才升级**；③ **禁止 NPC 两两全交互**，gossip 采用有界传播（fanout ≤3 跳）；④ 硬上限：Core 期间有名字 NPC ≤16，匿名 ≤60，锁死。

**R2 · 拾荒主循环的重复感**
*风险*："捡垃圾"在第 90 分钟塌成无意义的搬运劳动。
*缓解*：① 有限物资池 + claimant 标记——每次拾荒都告诉你"这原本是谁的"（叙事含义而非数值）；② **竞争拾荒**：NPC 也在捡，同一物件可能被 NPC 先取走；③ 负重/风险自调旋钮：每趟出发都是一次自选难度；④ 多变的目的地而非多变的掉落表——目的地由真实缺口动态生成（C9 工作板），而不是 Designer 手写清单。

**R3 · 对话树与模拟 NPC 的耦合**
*风险*：手写对话隐含"这个 NPC 站在原地且活着"，但模拟让他死了/走了/恨你 → 内容爆炸或失效。
*缓解*：① **两态写作法**：对话按**"意图/服务请求"**编写，而非绑定某个具体的人；"取水员承诺明日送水"是一个可被**任何符合岗位的 NPC 承接**的契约节点；② 稀缺的不可替代角色进 protected 名单（≤3 人），其余一律可替换；③ **替岗机制**：徒弟/邻居自动顶替空缺岗位，使服务请求不因某人死亡而悬空；④ 承诺即 Ledger Entry——违约产生的是**内容**（失望、声望、gossip），不是 bug。

**R4 · 范围失控**
*风险*：模拟型游戏天然可以无限扩展，工期被吞没。
*缓解*：① Core 的 NPC 数量与系统清单**硬性冻结**，必须先满足 Core 七条验收；② 每个新系统必须通过**"3 跳归因 + 可读性测试"**（P1/P2 双闸门）；③ Vision 每一项都必须先在 Core/Extended 有**最小探针**，不允许跨越式开工。

**R5 · 涌现叙事的失败模式：无菌与无张力**
*风险*：随机模拟最常见的产物不是故事，而是"什么也没发生"的平静荒土。
*缓解*：① **结构化播种矛盾**：每个社区天生被设计成结构性短缺（两社区共用一条季节性水源，一个控工坊一个控药品），张力不需要随机，只需要缺口；② **张力预算注入器**：每日结算时若"全局冲突指数"低于阈值，注入一个 authored 的缺口事件（枯井、来路不明的外人、屋顶塌了）；③ 所有随机事件必须可追溯——归因链可导出，绝不允许藏着美学声称。

## 六、电梯陈述与参考锚点

**电梯陈述**

> **《枯水期》是一款关于"没有政府、只有邻居"的后核战开放世界 RPG：你唯一的本领是拾荒，而这个世界里每一块垃圾原本都属于某个具体的人——他明天早上六点会准时去找它，找不到，他的孩子今晚就没水喝。**

**三个参考锚点**

| 锚点 | 借鉴什么 | 不借鉴什么 |
|---|---|---|
| **《辐射：新维加斯》**（Obsidian, 2010） | 局部且互相排斥的阵营声望、互斥的政治路线、"把属性/技能变成对话里的动词"（`[科学 55]`）、"荒原上的人就是内容"。 | 不借鉴其"仍然存在一个宏大战略棋局"的结构——本作没有军团与 NCR，只有河谷与井窖。 |
| **《剑士》Kenshi**（Lo-Fi Games, 2018） | 世界不因玩家而待机；NPC 有自己的路线、目标与聚落命运；"用需求代替任务列表"；失败是状态而非结局。 | 不借鉴其 UI 密度门槛与极端的无引导（本作需要更强的可读性保证，这是 P2 存在的理由）。 |
| **《环世界》RimWorld**（Ludeon, 2018） | **把模拟状态翻译成玩家读得懂的叙事句子**的能力；需求条与岗位的可见化；"故事发生器"的设计哲学。 | 不借鉴其上帝视角经营层——本作视角必须贴地，才能满足 P1 的"一次短途步行"尺度。 |

*佐料级参考（不计入正式锚点）*：
- **《极乐迪斯科》**（ZA/UM, 2019）——"低预算、高文本密度"的可行性证明：需要文本深度时可以完全不依赖美术与演出。
- **《Pathologic 2》**（Ice-Pick Lodge, 2019）——每日限时压力下的稀缺经济与以物易物，"世界对你毫不留情"的节奏感。

## 七、待拍板的开放问题

1. **视角与呈现**：第一人称（文本沉浸强，但无法通过肢体动作读 NPC）**vs** 第三人称近视角（能看见 NPC 姿态、动作与视线 → 对 P2 极其有利）。**主笔倾向：第三人称近视角**。
2. **站队互斥是否升格为正式 P5**：目前压进 P1+P4 作为硬规则。若希望它拥有一票否决权，需展开为第五支柱。
3. **成就系统的 KPI 改写**：为避免 Achiever 型"刷光全图"与 P4 冲突，建议把成就定义为**可持续性指标**（某社区安全天数 >60、某商路连续 X 日无断供、带出某学徒满级）。
4. **是否接受"最多 16 个有名字 NPC"这个冷酷上限**：这是保证"每个都值得写回忆"的前提，也是 R4 的第一道锁。
5. **后续推进**：是否进入 Phase 2（系统拆解 → 逐系统 GDD）。建议优先四份：**NPC-Simulation / Scarcity-Loop / Dialogue-Contract / Economy-Barter**。
