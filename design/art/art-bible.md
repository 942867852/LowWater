## 1. 视觉主张：为「读懂」服务，不为「好看」服务

> **一句话主张：世界的每一个像素，要么在告诉你「谁、几点、在哪、缺什么」，要么在告诉你「这块地是谁的地」。读不出信息的华丽，在本作里是失败。**

**依据**：八美学全序（`game-concept.md` §3.3）——**Discovery × Narrative 主打**；**Fantasy 刻意矮化**；**Sensation 刻意不做**。全部预算优先投给"让玩家看见并读懂系统"的呈现件，而非美术奇观。

**三条入场判据（任何视觉方案上场前必须全过）**

| # | 判据 | 不过的后果 |
|---|---|---|
| **I1 信息判据** | 它是否承载或增强 C-1~C-4（时间锚/岗位/路线/携带物）· 四种 WorldSignal · urgency 五级介质之一？ | 不承载 → 砍 |
| **I2 低配判据** | 它在 GTX 1060 / 1080p 下负担得起（逐项见 `asset-spec.md §6`）？ | 超预算 → 走降级或砍 |
| **I3 尺度判据** | 它能在"一次短途步行"（P1）内落到**某个有名有姓的人**身上被验证吗？ | 落不到人 → 砍 |

**服从链（冲突时的裁决序）**：**形式服从可读性 → 可读性服从邻居尺度 → 邻居尺度服从「世界不为你待机」。**

## 2. 色彩与明度体系

**唯一可靠通道是明度，不是色相。** 色相定位 = **冗余**：只做两件事——① 加速熟悉玩家的识别；② 承载废土氛围。**色相不承担任何唯一信息**（`accessibility §2.3`）。

**明度地板（量化，成像后实测，非贴图设计值）**

| 规则 | 值 |
|---|---|
| 同通道两状态明度差 | CIE L\* **≥ 18** |
| 载体 vs 背景对比比 | WCAG **≥ 4.5:1**（≥24px 或粗体 ≥19px 时 ≥3:1） |
| 信息载体最小屏占比 | 屏高 **≥ 1.6%**（1080p ≈ 17px）；线状载体 ≥1.5px + 1px 暗描边 |
| 校验 | 截帧 → 载体包围盒前景/背景像素 → 算 ΔL\* 与对比比；正午/黄昏/夜各跑一次（`--assert-legibility`） |

**氛围基调（色相，仅氛围）**：废土的**土黄 / 锈红 / 灰绿**。两社区可读区分（冗余，非唯一判据）：

| 社区 | 基调 | 由来（地形即经济表） |
|---|---|---|
| 河谷 `he_valley` | 湿泥**青灰** + 木本色 + 锈红金属 | 低洼冲积·季节河·沙化土（有水无粮） |
| 井窖 `jing_cell` | 黄土**赭** + 生砖白 + 灰绿药圃 | 黄土台地·竖井窑院·水层深（有药无致命缺水） |

**规则**：① 色盲三档 = 后处理色彩矩阵（1 fullscreen pass，<0.05ms @1060），**即便不开，三重编码也成立**；② 任何"红色警告"必须同时有**材质或形状**替换；③ **禁止**用闪烁频率作唯一通道（光敏风险 + 属 Sensation）。

## 3. 形状语言（全局唯一编码源 = `accessibility.md §2.1`）

**决定：全作信息视觉只用一套形状表，禁止任何系统自建第二套图标。**

| 层 | 编码什么 | 取值 |
|---|---|---|
| **形状 glyph** | "它是哪一类" | 10 值闭集：水滴·碗·月牙·竖菱形·双扣环·盾·火焰·排夹·十字·芽 |
| **底盘** | "它是哪种东西" | **圆形**=需求/状态 ｜ **方形**=物资/簇 ｜ **无底盘**=一个人（名字 + 职业形状） |
| **填充** | "它有多急/多重要"（非可数） | 空心描边 · 半填充 · 实心+粗描边 |

- **跨域复用**：竖菱形 圆底盘读"怕/安全"、方底盘读 `AMMO`——**底盘是消歧键**，故同一形状可跨域复用，形状表压到 10 个，玩家只学一张表。
- **六处同一套表**：需求气泡槽位 / 字幕说话者名签 / 工作板介质标记 / 地图手绘记号 / 容器标记 / `observeRadius` 内交互提示。
- **静态替身**：运动关闭时，severity 由**形状边缘破损**承载（完整 / 缺口 / 斜线划裂）——"关掉动画"不损失任何信息。
- **纪律**：任何"这里想再画个图标"的诉求，必须先证明它落在 10 glyph × 3 底盘内，否则不予立项。

## 4. 材质与表面

**核心手法：用「新/旧、压实/翻松、被改造/未改造」的材质差承载信息，而非用颜色或发光。**

**关键材质对（ΔL\* ≥ 18 是硬要求）**：翻出的湿土 vs 压实旧径 · 新木/新绳 vs 风化木 · 赭红颜料 vs 炭字 · 被刨凹的板面 vs 完整板面 · 金属片单点镜面高光（**全作唯一允许的"闪"，且它是一枚实物**）。

**反射率梯度（低 → 高）**：压实地面 < 旧木 < 生砖 < 新木/新绳 < 翻土 < 金属片。夜景与低照度全靠这条梯度读物。

**夜间可读性（R-S2）**：**材质反射率差 + 掠射自阴影**（贴花带法线，夜间法线强度上调 **1.6×**——不是加光，是加深自阴影）；**禁自发光描边**。

**表面对几何的优先序**：贴花/法线 > 几何细节；**垂直元素（≥15cm，R-S1）> 地面贴花**。理由：第三人称眼高 ≈1.6m，纯地面贴花在屏幕上被压缩到 2–3px，等于不可读。

## 6. 构图与镜头语言

- **第三人称近视角**；眼高 ≈ **1.6m**；**禁第一人称切换 / 过肩瞄准特写**（P2 需要看见姿态与视线）。
- **可读性保持锥**：屏幕中心水平 **±25°** / 垂直 **±20°**；信息载体切换**只允许发生在锥外**，0.2s 交叉淡入，**禁 pop**（N2）。
- **距离分档（构图即信息）**：0–8m 完整（气泡+姿态+携带物）｜8–25m 携带物剪影+步频+剪影轮廓｜25–60m 剪影+是否带灯（三值）｜>60m 一个点（只承诺"那里有人"）。
- **构图三原则**：
  1. **纵深优先于广角**：2×2km 靠"通路 + 地标"读向，**不做上帝视角鸟瞰**（P1 否决全图 UI）。
  2. **岔路口是构图主角**：WorldSignal 的脚印链/绊线必须在岔口、在判读半径（= `observeRadius`，地板 4.0m）内可读。
  3. **地标即导航**：废墟轮廓、总站混凝土外院、油罐群构成天际线锚点，**不依赖地图 UI**。
- 相机可调：距离 / FOV / 灵敏度 / 反转 / 摇晃开关（`accessibility` C-5/C-6）。

## 7. 角色与群体视觉

- **渲染分级**：**32 full 模型 / 88 简模**（`renderLOD`，视锥私有、不进 simLOD）。**转头只让远处 NPC 变简模，不改其作息**（ADR-003 D2）。
- **同一 NPC 形状两日必须完全一致**（C-2 验收通道）：`homePost` 世袭 → 岗位 glyph 固定；**零随机抖动**（不随机装扮、不随机晃动、不随机步频）；语义不因距离/画质/昼夜改变（N3，升级只增冗余不换语义）。
- **岗位形状（无底盘=人 + 岗位 glyph 名签）**：S0 §D 的 role 闭集为 **6**（water/watch/patrol/mend/care/idle），S9 §6.1-C2 写"8 岗位"——本文档按 6 个权威 role 给形状表并**预留 2 个形状位**（盾=SWORN 守望/议事主持，芽=耕养/留种），以满足 8 形状并为 Extended 留位 → **见 ⑥ 待裁决**。逐岗位映射见 `asset-spec.md §3.3`。
- **携带物剪影五档**（`carryingSilhouette`：桶/灯/工具/袋/无）：**8–25m 唯一的 activity 载体**，与岗位固定映射，**不得移除、不得替换为图标**。
- **群体尺度**：≤16 有名字（每个都值得被记住、字形可辨）+ ≤60 匿名（简模池，只要求"像是这地方的人"，不要求个体可辨）。**明确不追写实**：低多边形 + 手绘贴图；**姿态优先于面部**，面部细节属"可自由降级"项。

## 8. 环境与地标

**2×2km 手写地形**（禁程序化地形）· 13 节点路径 · 21 容器 · 6 废墟 zone + 2 社区 + 1 旧政权设施。

**两社区的建筑语言差异（地形即经济表，走一趟就懂谁依赖谁）**

| | 河谷 `he_valley` | 井窖 `jing_cell` |
|---|---|---|
| 地形 | 低洼冲积·季节河·沙化土（不可耕） | 黄土台地·竖井窑院·水层深 |
| 建筑语汇 | **木 + 泥 + 脚手架**，抬高地坪防潮，屋顶轻质 | **黄土夯筑 + 生砖 + 窑洞**，下沉院落，厚墙小窗 |
| 天际线 | 低矮、散、贴地 | 下沉、围合、有竖井与烟道点 |
| 色相氛围 | 湿泥青灰 + 木本色 | 黄土赭 + 生砖白 |

**旧政权配水总站 `admin_yard`**：**混凝土外院 + 配额墙 + 空档案柜**。它是**全图唯一的"国家尺度"建筑**（高、硬、非民居）——这一处尺度反差本身就在说"国家死了"；它无信条（黑市·跨社区唯一接触点），建筑语言 = 冷灰混凝土 + 剥落标语。

**废墟模块化拼装**：一套 kit（墙/柱/板/门框/管/罐）拼出 6 个 zone；**不做会刷新的据点**。

**21 容器的外观分级（三种形态，**一眼可辨且不依赖颜色**）**

| tier | 外形 | 判据（非色相） |
|---|---|---|
| 普通 | 敞开 / 可及 | 无锁、无遮挡 |
| 稀缺 | **带锁 / 需拆** | 有锁件、覆板、需 `dismantle` 的接缝 |
| 关键 | **锚点标记** | 挂件 / 刻字 / 独一件感 / 与场景叙事绑定（如地窖、军用箱） |

**垂直元素（R-S1）贯穿环境**：桩 / 杆 / 钩 / 门檐 / 液位管 ≥15cm——它们在低角度光下是唯一可靠的高度载体。

## 9. 禁忌清单（明确不做什么）

**Sensation 的判据（不是效果名，是四条判据——满足任一即判为感官奇观，不做）**

| # | 判据 |
|---|---|
| **T1** | 主要目的是"让人惊叹"，且**移除后不损失任何一条信息通道** |
| **T2** | 需要"屏幕级"强度（自发光 / 全屏后处理 / 体积效果 / 时域累积）才能被看到 |
| **T3** | 会**压缩对比度**或**掩盖世界内信号**（尤其压过 NPC 火光剪影这条真信息通道） |
| **T4** | 让玩家"看着效果"而非"读着世界"（把注意力从人与缺口上拉走） |

**明确不做（承接 `accessibility.md §9` 自我否决 7 条）**：① 自发光描边（夜间可读）→ 反射率差 + 掠射自阴影；② 需求气泡粒子/流光 → 图集 billboard；③ 全屏轮廓描边 → 焦点 1 个描边 + 形状标记；④ 慢镜头/命中停顿 → 短促相机位移 + 音效 + 世界内后果；⑤ 电影级 LUT + 体积光 → 单方向光 + 色温曲线；⑥ urgency 血迹/裂纹**动态扩散** → 静态介质；⑦ 远处 NPC 头顶信息板 → 携带物剪影。

**本作额外三条禁令**：⑧ **禁第二套图标集**（强制复用 10 glyph × 3 底盘）；⑨ **urgency 禁数字与一切可数化替身**（星级 / 条形 / 进度 / 刻度）；⑩ **禁"为了好看"的对称与装饰**——任何装饰若与信息无关，砍掉。

**一句话纪律**：**当"美"与"可读"冲突时，永远选可读；当"可读"与"邻居尺度"冲突时，永远选邻居。**
