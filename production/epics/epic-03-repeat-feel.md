# Epic 03 · 重复感测试通过（Core 验收 3）

- **指向**：`game-concept.md §四-CORE 验收 3` ｜ `control-manifest.md §3`（45 分钟自由游玩 + 自设目标编码表）｜ `07-work-board.md §8 A9` ｜ `01-scarcity-loop.md §8 验收 2`（边际收益非 flat）
- **一句话验收**：12 名测试玩家**无任务指引**自由游玩 45 分钟，**≥70% 在第 45 分钟仍有自设目标**，且人均自设目标数 **≥2**（自设，非工作板给的）。
- **为什么人工**：测的是"玩家还有没有自己想做的事"，无法用代码替代（`control-manifest §3`）。本 Epic 提供**载体**（工作板世界物件 / 世界读数）与**埋点工具**。
- **涉及系统**：S7（缺口工作板，C9）· S9（板是世界物件 + 随身笔记）· S1/S3/S5（缺口来源，消费）
- **涉及契约**：`GapSignal` · `WorkOrder`（契约 7 字段 + 派生量）· `Board`/`BoardNote` · `SimViewBoard`/`SimViewWorkOrder`（投影，`urgency` 数字**不渲染**）
- **依赖**：Epic 01（`GapSignal` / `safeDays` / 岗位）· Epic 00
- **放行闸门**：`E3-S3` 触碰表现层 → **需 1060 冒烟（闸门 B）**

---

## 目标与验收

| 判据 | 内容（`control-manifest §3`） |
|---|---|
| 3a | **自设目标**操作性定义：受试口述/书写、可编码到 6 类（`G-ACCUM/G-ROUTE/G-SOCIAL/G-EXPLORE/G-ARBITRAGE/G-RECOVER`）；**`WorkOrder` 上的条目不计入** |
| 3b | **"仍有"**：第 45 分钟时受试还能说出 ≥1 个未完成的自设目标 |
| 3c | 通过阈值：**≥70%（即 ≥9/12）**；人均目标数 **≥2** |
| 3d | **双盲编码**：两名编码员独立编码，Cohen's κ ≥ 0.8 方可采信 |

> **C9 立场**：权威真空里不存在"任务发布者"，只有"缺口"。**板在空的日子里目标数不得为 0**（S7 A9）——`safeDays` 与 `trendDelta7d` 必须足以支撑自设目标。

## Story 清单

### ★ E3-S1 · S7 工作板投影（`GapSignal → WorkOrder`，**写入量 = 0**）
- **判据（跑 Y 得 Z）**：`--dump-board <cid> <day>` 输出条目 + `sourceSignalIds` + 完整排序键 + `haulFit`；`--assert-board-no-write` 断言 S7 侧写队列条目数 == 0、`ReputationDelta` 数 == 0；`qty` **永不缩水**。

### ★ E3-S2 · S7 排序 / 去重 / 沉降 / 回填确认

### ★ E3-S3 · S9 工作板世界物件 + 随身笔记（`BoardNote`/`frozenAt`）　【需 1060 冒烟】
- **判据（跑 Y 得 Z）**：板是**世界物件**，只在 `observeRadius` 内可读（`--assert-board-observe-radius`，无 Tab 全图面板）；离板 → `BoardNote{frozen, frozenAt}` 必非空且顶部常驻；行程时间/`state` 用**过去时**；`--assert-board-no-ordinal` 断言行号/序号/缩进/列表点 == 0；无"接受"控件。
- **涉及契约**：`SimViewBoard`/`SimViewWorkOrder` · `Board.locationId` · `BoardNote`
- **触碰 Godot 表现层**：**是** ｜ **需 1060 冒烟**：**是（闸门 B）**
- **前置**：E2-S1 · E3-S1/S2 ｜ **工作量**：2 人日 ｜ **可并行**：✓
- **备注**：`urgency` 数字与一切可数化替身**不渲染**（裁决 21/32）。

### ★ E3-S4 · 自设目标埋点（`goal_probe` + 5 分钟轻提示 + 编码表）
- **判据（跑 Y 得 Z）**：每 `SIM_TICK` 记录玩家位置/背包/`WorkOrder` 视线/最近 3 次交互；每 5 分钟一次轻提示"你现在想做什么？"（自由文本，不给选项）；`tools/goal_probe.py --session <id> --dump-actions` 输出目标声明时间戳 + 行为轨迹 + 放弃点。
- **涉及契约**：无（埋点，仅诊断/编码）
- **触碰 Godot 表现层**：**是（埋点接入）** ｜ **需 1060 冒烟**：是（随盲测环境）
- **前置**：E3-S3 ｜ **工作量**：2 人日 ｜ **可并行**：✓
- **备注**：行为侧数据**不替代口述**，只用于发现"说得出但没做 / 做了但说不出"。

### E3-S5 · 验收 3 执行（**人工**，执行方：测试 严守真）
- **判据（跑 Y 得 Z）**：12 人 × 45 分钟自由游玩 → ≥70% 仍有自设目标、人均 ≥2；双盲编码 κ ≥0.8。
- **涉及契约**：无（人工协议）
- **触碰 Godot 表现层**：**是（被测对象）** ｜ **需 1060 冒烟**：是（同 E2-S7 环境）
- **前置**：E3-S1..S4 · E2-S1 ｜ **工作量**：人工（≥2 轮）｜ **可并行**：✗
- **备注**：**红线关联**：概念文档规定"任何新增功能必须先证明自己能通过验收 1 与 3"→ 新系统接入时本测试**必须重跑**。
- **失败定位**：`G-ROUTE/G-EXPLORE` 缺 → 世界信号不足（S2/S8）；`G-SOCIAL` 缺 → 记忆/传闻耦合不足（S4/S6）；`G-ARBITRAGE` 缺 → 价差信号不足（S3）。
