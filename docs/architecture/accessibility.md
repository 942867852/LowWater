## 1. 三级可访问性分级

### 1.1 分级依据：缺失该能力时，哪些核心动词会失效

分级**不是**按"功能多寡"，而是按**核心动词的失效边界**。8 动词：读 OBSERVE / 取 SCAVENGE / 负 HAUL / 制 FABRICATE / 易 BARTER / 说 PERSUADE / 站 ALIGN / 守望 TEND。

判据一句话：**某级之下，不允许出现"因为玩家的感知或操作能力，某个核心动词从可执行变为不可执行"的情形；只允许出现"执行它需要多花时间/多走一段路"的情形。**

### 1.2 三级定义与准入底线

| 级 | 目标玩家画像 | 准入底线（一句话） |
|---|---|---|
| **Basic** | 色觉障碍 + 听力受损 + 输入精度/速度受限 + 阅读偏慢的玩家 | **在 Basic 下，8 个核心动词全部仍可执行，且世界给出的每一条信息都至少有一个非色相、非听觉、非时限的载体。** |
| **Standard**（出厂默认） | 上述 + 需要自定义呈现与输入的用户 | **玩家可以只靠一个感官通道（纯视觉或纯文本）跑通核心循环，且 45 分钟内不需要任何一次快节奏或限时输入。** |
| **Comprehensive** | 上述 + 认知负荷敏感 / 需回放与外部化信息的用户 | **任何一条信息都能被回看、被转成文字、被慢放；不存在"错过就永远没了"的信息——唯一的例外是 P3 本身（世界不等人），此时必须给 ≥1 游戏日的补偿窗口。** |

**三级之间的不可逾越线（防止"可访问性选项"变成"难度选项"）**

1. Basic 的全部能力**不得被任何画质/难度设置关闭**（见 §7.3 不可关闭清单）。
2. **Standard 与 Comprehensive 不得提供"世界暂停"**——P3 是支柱，暂停会直接击穿它。Comprehensive 提供的是**"你读多久都行"**（阅读无时限 ≠ 世界停下），代价照常发生。需要世界减速的，走第十节裁决 2/3。
3. 任何一级都**不得**为玩家裁剪世界：`GapSignal.qty` 不缩水、`safeDays` 不美化、`pressure` 不放假。可访问性只改**信息如何到达玩家**，不改**世界是什么样**（与 S7 §7-E4 同款兜底断言）。

### 1.3 与本作支柱的关系（尤其两条易被误伤的）

| 支柱 | 可访问性方案必须服从的点 |
|---|---|
| **P2 看得见的作息** | 本份的全部信息通道都是 P2 的实现件。Basic 级 = P2 的**最低可执行保证**（与 S2 A6「`visibleSignal` 非空率 100%」同级，不接受例外）。 |
| **P3 世界不为你待机** | 可访问性**不得**通过"暂停世界"兑现。改为：日志、回放、摘要、减速（需裁决）。 |
| **P1 只有邻居** | 信息载体必须是**世界里的一件东西**（板上的字、门上新加的锁），不是 HUD 上的抽象图标。§4/§5 全部方案都是世界内物件。 |

## 2. 全局视觉字母表（所有信息通道的唯一编码源）

> **决定**：全作信息视觉只用**一套形状表**，贯穿需求气泡 / 字幕名签 / 工作板 / 地图手绘记号 / 容器标记。**禁止任何系统自建第二套图标**（防认知过载，与"防第二套骰子"同款纪律）。

### 2.1 三层编码：形状 × 底盘 × 填充

| 层 | 编码什么 | 取值 |
|---|---|---|
| **形状 glyph** | "它是哪一类"（10 值闭集） | 水滴·碗·月牙·竖菱形·双扣环·盾·火焰·排夹·十字·芽 |
| **底盘** | "它是哪种东西"（3 值） | **圆形** = 需求/状态｜**方形** = 物资/簇｜**无底盘** = 一个人（只有名字 + 职业形状） |
| **填充** | "它有多急/多重要"（3 档，非可数） | 空心描边（1）· 半填充（2）· 实心 + 加粗外描边（3） |

**形状闭集（10）与其归属**

| glyph | 造型（16×16 可辨） | 需求侧 | 物资侧（`ClusterId`） |
|---|---|---|---|
| 水滴 | 上尖下圆 | 渴（`PHYSIO_WATER`） | `WATER` |
| 碗 | 开口向上的半圆 | 饿（`PHYSIO_FOOD`） | `FOOD` |
| 月牙 | 横躺的闭合弧 | 困（`PHYSIO_SLEEP`）· 夜 | — |
| 竖菱形 | 上下尖、左右窄，锐角 | 怕 / 安全（`SAFETY`） | `AMMO`（配方形底盘区分） |
| 双扣环 | 两个相扣圆环 | 社交（`SOCIAL`） | — |
| 盾 | 上宽下尖六边形 | 信条（`CREED`） | — |
| 火焰 | 带缺口的竖三角 | — | `FUEL` |
| 排夹 | 方括号形 + 底横线 | — | `AMMO` |
| 十字 | 等臂正十字 | — | `MEDS` |
| 芽 | 小圆 + 一道向上的短芽 | — | `SEED` |

> **`AMMO` 用两个 glyph 的说明**：竖菱形/排夹在圆形底盘下读作"怕"，在方形底盘下读作"弹药"。底盘是消歧键，因此**同一形状允许跨域复用**——这使形状表压到 10 个，玩家只需学一张表。

### 2.2 明度地板（色盲友好的量化表达）

| 规则 | 值 | 说明 |
|---|---|---|
| **同通道状态差** | 任意两个必须被区分的状态，CIE L\* 差 **≥ 18** | 在红绿混淆轴上，明度差是唯一可靠的剩余通道 |
| **载体 vs 背景** | WCAG 对比比 **≥ 4.5:1**（≥24px 或粗体 ≥19px 时 **≥ 3:1**） | **成像后**实测，不是贴图设计值 |
| **最小屏幕尺寸** | 信息载体 ≥ 屏高的 **1.6%**（1080p ≈ 17px）；线状载体 ≥ **1.5px** 且带 1px 暗描边 | 低于此即关闭该载体，改由冗余通道承担 |
| **校验方式** | 截帧 → 对载体包围盒取前景/背景像素 → 算对比比与 ΔL\* → 低于地板即失败；正午/黄昏/夜各跑一次 | 归 L4 工具链（`--assert-legibility`），成本 <1 人日 |

### 2.3 色相的地位：冗余，不是通道

色相在本作**不承担任何唯一信息**。它只做两件事：①加速熟悉玩家的识别；②承载氛围（废土的土黄/锈红）。因此：

- **色盲模式三档**（关 / 红绿 / 蓝黄）实现为后处理色彩矩阵（1 个 fullscreen pass，**<0.05ms @1060**），**即便不开，三重编码也成立**。
- 任何"红色警告"必须同时有**材质或形状**的替换（见 §5 的 u4/u5）。
- **禁止**用"闪烁频率"作为唯一通道（光敏性癫痫风险；且闪烁是 Sensation）。

### 2.4 renderLOD 的信息三不变（承接约束 2）

`simLOD` 剔除视锥后，仿真侧信息恒定；风险全部转移到"渲染换画法"的瞬间。三条硬规矩：

| # | 不变 | 具体规则 |
|---|---|---|
| **N1** | **不变内容** | 任何 `renderLOD` 档位下，NPC 的「当前 activity 粗分类 + 需求气泡状态」**必须有至少一个可见载体**。可以换载体，**不允许**"远了就什么都没有"。 |
| **N2** | **不变时刻** | 载体切换只允许发生在**可读性保持锥之外**（屏幕中心水平 ±25°、垂直 ±20° 之外）；切换用 **0.2s 交叉淡入**，禁止 pop。 |
| **N3** | **不变语义** | 载体编码表全局唯一（§2.1），**不因距离、画质档位、昼夜而改变含义**。升级只能**增加冗余**，不能替换语义。 |

**远距离 activity 载体分级**（这是"转头不错乱"的答案）

| 距离带 | 载体 | 可判读内容 |
|---|---|---|
| 0–8 m | 需求气泡 + 姿态 + 携带物 | 完整：他在做什么 + 他缺什么 |
| 8–25 m | 携带物剪影 + 步频 + 剪影轮廓 | activity 粗分类（取水/守夜/巡线/修补/育儿/闲坐/睡/警觉） |
| 25–60 m | 剪影轮廓 + 是否自带光源 | 静止 / 移动 / 有灯（三值） |
| > 60 m | 一个点 | 只承诺"那里有人"，**不承诺 activity 可读**（P1 的"一次短途步行"尺度在此之外） |

> **为什么转头不会错乱**：气泡槽位锚定在角色**局部空间**（billboard 面向相机，但槽位偏移固定），转头不改变相对排布；且内容由 simcore 提供，`renderLOD` 无权改。玩家看到的只是"画法变了"，不是"他换了个活儿"。

## 3. 需求气泡系统（本作最高频的信息通道）

### 3.1 先回答色盲：三重编码的设计顺序

**顺序不能反**：先定**形状**与**槽位**（色盲可辨），再定**运动**，最后**才允许**加色相。色相不进前三步。

| 编码轴 | 承载 | 取值 |
|---|---|---|
| **①形状** | 是哪一类需求 | §2.1 的 10 glyph；生理三值（渴/饿/困）**共用头顶槽**，靠形状区分 |
| **②位置（槽位）** | 是哪一大类 | 固定钟点位：**12 点 = 生理**（水/食/睡取最急者）· **10 点 = 安全** · **2 点 = 社交** · **6 点 = 信条**（默认隐藏，见 §3.4） |
| **③运动** | 有多急（S2 §3.1 的 severity 1/2/3） | 档1 **静止**；档2 **呼吸缩放**（0.90–1.05，周期 2.4s）；档3 **急跳 + 摆角 15°**（周期 0.8s，幅度 1.00–1.18） |
| ④填充（冗余，非必需） | 同 severity | 空心 / 半填充 / 实心+粗描边（§2.1） |
| ⑤色相（冗余，可删） | 无唯一信息 | 一律可关 |

**运动敏感用户的静态替身（必须存在）**：运动可整体关闭。关闭后，severity 由**形状边缘的破损**承载——档1 边缘完整；档2 边缘有一处**缺口**；档3 被一道**斜线划裂**。这保证"关掉动画"不损失任何信息。

> **为什么不用"气泡大小"或"气泡数量"表示严重度**：大小在低照度与远距离下退化最快（正是最需要读的时刻）；数量是可数化替身，与裁决 21 的精神冲突。

### 3.2 可读性下限与 1060 成本

| 项 | 规格 |
|---|---|
| 显示条件 | 有名字 NPC（≤16）**或** 距玩家 < 30m 的匿名 NPC；且屏幕尺寸 ≥ 1.6% 屏高 |
| 同时显示数 | **≤3 个标记 / NPC**（认知上限） |
| 最小尺寸 | 17px @1080p；低于此关闭气泡，改由携带物剪影承担（N1 仍满足） |
| 1060 成本 | 图集 + instanced billboard，≤72 quad、1 个 draw call，**< 0.10 ms/帧**。✅ 负担得起 |
| 仿真成本 | **0**（只读 `ViewSnapshot`） |

### 3.3 与 S2「严禁再画一套渴/饿」的关系（不违反裁决 1）

气泡**不是第二套数值**：它是**单一渲染器**，同时读 `PhysioState`（S1 写）与 `NeedVector`（S2 写）并投影到同一套形状表。气泡层**不持有、不缓存、不修改**任何数值；水/食/睡的唯一权威仍在 `PhysioState`。

### 3.4 信条槽的默认值（待裁决，见 §10-6）

S2 §6-4 明写"需求气泡只画三条"。本份**默认关闭信条槽**（6 点位），仅在两种情况下开启：①玩家已加入该 NPC 所属社区（站 ALIGN 完成）；②玩家在设置里开"高信息模式"。默认态 = 3 槽，与 S2 逐字一致。

## 4. WorldSignal 四种可见信号的视觉规格

> **共同硬规则 R-S1（本份最重要的一条工程规则）**：每个信号**必须包含一个 ≥ 15cm 的垂直元素**。理由：第三人称近视角相机高度约 1.6m，纯地面贴花在屏幕上被压缩到 2–3px，等于不可读；垂直元素提供高度方向的投影长度，是低角度光照下唯一可靠的载体。

> **共同硬规则 R-S2（夜间可读性）**：**禁止自发光描边**（它是 Sensation，且会压过 NPC 火光剪影这条真正的信息通道）。夜间可读性由两条免费手段承担：①**材质反射率差**（翻土/新木/新绳比周围压实地面更亮，ΔL\* ≥ 18）；②**掠射自阴影**（贴花带法线，夜间把法线强度上调 **1.6×**，不是加光，是加深自阴影）。

> **共同硬规则 R-S3（判读半径）**：**判读半径 = `observeRadius` = 4 + 0.6 × MIND（米）**，即"心智越高，越远就能判读"——这是 S0 §A2 已定的派生量，本份不新增数值。**硬地板：所有信号在 4.0 m（MIND=1）内必须可判读。** 判读半径之外只给"注意"（剪影/明度异常），不可判读。

### 4.1 `REROUTE` → `FOOTPRINT_DEVIATION`（岔口偏离旧小径的新脚印）

| 项 | 规格 |
|---|---|
| 视觉语言 | 一条**偏离旧小径**的新脚印链；旧径被踩实、色深、嵌碎石；新脚印是**翻出的湿土**，更亮、边缘有碎块 |
| 垂直元素（R-S1） | 被踩倒的草茎 / 被踢起的石块（15–25cm），**朝向新方向**——朝向本身就是信息 |
| 注意半径 / 判读半径 | 12 m / = `observeRadius`（地板 4.0 m） |
| 低照度 | 翻土的高光 + 掠射自阴影（法线 ×1.6）；火把掠过时**一次性闪出链状阴影**，这既是可读性也是 Discovery 美学 |
| 编码冗余 | 形状（链状延伸方向）+ 明度（新旧土 ΔL\* ≥ 18）+ 垂直元素朝向；**无色相依赖** |
| 1060 成本 | 贴花 6–10 个 + 3–5 个小 mesh（石块/草丛），**< 0.15 ms**。✅ |

### 4.2 `ADD_WATCH` → `WATCH_ADDED`（多出的过夜灯、坐具、一个不再赶路的人）

| 项 | 规格 |
|---|---|
| 视觉语言 | 三件套同现：**一盏灯（低矮、有罩、光是暖的且被罩住）＋ 一件坐具（凳/箱/垫）＋ 一个人**（静止、不赶路） |
| 垂直元素（R-S1） | 灯杆或吊点 60–90cm；坐具 40cm；人 1.7m。三者在剪影上形成"高低高"的节奏 |
| 注意半径 / 判读半径 | **夜间 30 m（火光本身）** / 白天 20 m（坐具剪影）；判读"是有人在守"需 6 m |
| 低照度 | **本条是全表唯一的例外**：夜里"多了一个光源"本身就是信息，且它是**光源而不是特效**（不违反 Sensation —— 废土的夜本来就该有人点灯）。光源数 ≤2，半径 ≤4m，无体积光 |
| 编码冗余 | 三件套（数量固定为 3，是"这一套"不是"3 级"）+ 剪影节奏 + 静止 vs 移动 |
| 1060 成本 | 1 个点光源（无阴影或 512 阴影）+ 2 个小 mesh + 1 个 actor，**< 0.25 ms**（场内同时 ≤3 处）。✅ |
| 反向安装（降级） | 灯灭、坐具被搬走、**人开始赶路**。残留：地面上一圈**压痕与灰烬圈**（仍是"这里曾有人守"） |

### 4.3 `DEEPEN_STASH` → `STASH_MOVED`（柜子被拖进更深的屋子）

| 项 | 规格 |
|---|---|
| 视觉语言 | 三件同现：**拖拽沟槽**（深 4cm，两道平行）＋ **空绳印**（地面上的浅色矩形压痕）＋ **原址那块"空"**（尘土边界围出一个颜色略深的方块，家具移走后地面反射率与周围不同） |
| 垂直元素（R-S1） | 沟槽翻起的土棱（15cm）+ 门口/墙角残留的绳头或挂钩（有高度） |
| 注意半径 / 判读半径 | 8 m / = `observeRadius`（地板 4.0 m） |
| 低照度 | 沟槽的掠射自阴影；"地面空了一块"在暗处表现为**反射率突变**（这不需要光，只需要材质差） |
| 编码冗余 | 沟槽（连续、有方向，指向**新址**）+ 空块（矩形、明确的人工边界）+ 绳印；三者互相印证 |
| 1060 成本 | 2 个沟槽贴花 + 1 个矩形贴花 + 1–2 个小 mesh，**< 0.15 ms**。✅ |
| 反向安装 | 柜子被搬回门边；沟槽被踩平并长草；**绳印还在新址的地上**（一前一后两处绳印 = "搬过去又搬回来"）。这是纯视觉的"他被说服了" |

### 4.4 `SET_TRAP` → `TRIPWIRE`（绊线 / 铃铛 / 松动踏板）

| 项 | 规格 |
|---|---|
| 视觉语言 | **两根木桩（20–30cm）＋ 一条水平细线（浅色麻绳，高 L\*，不用铁丝）＋ 线上挂一枚金属片或铃铛** |
| 垂直元素（R-S1） | 木桩本身即垂直元素；线的高度（踝/膝）是**语义**（绊/绊倒） |
| 注意半径 / 判读半径 | 6 m（金属片的单点高光）/ = `observeRadius`（地板 4.0 m） |
| 预警时间 | 步行 1.4 m/s → 4.0 m 给出 **≥ 2.8 s** 预警。满足"偷转为负收益"而非"偷必受伤" |
| 低照度 | 浅色麻绳的高 L\* + 金属片在有光时的**单点镜面高光**（1–2px，不是发光，是已有光源的反射）。**这是全作唯一允许的"闪"，且它是一枚实物** |
| ⚠ 抗锯齿冲突 | **TAA 会把 1px 细线吃掉**（时域累积 + 抖动）。见 §7.2 与 §10-5 |
| 1060 成本 | 2 个小 mesh + 1 个贴花线，**< 0.10 ms**。✅ |
| 反向安装 | 铃铛被摘、**桩还在、线上空了一截**。"残留的桩"是视觉上的"这里曾经不信任你" |

### 4.5 四信号互可区分（判读决策树）

```
先问：它有高度吗？
├─ 无（纯地面）
│   ├─ 是"链状、有方向" → REROUTE（脚印）
│   └─ 是"矩形空块 + 沟槽" → DEEPEN_STASH（搬走了）
└─ 有高度
    ├─ 有光源 + 有坐具 + 有人 → ADD_WATCH（有人守）
    └─ 有细横线 + 木桩 → SET_TRAP（别踩）
```

> **只有四种，没有第五种**（S2 §6-3）。任何新的世界信号必须先证明它能落进这四类的视觉语法，否则视为未实现。

## 5. 紧迫度的非数字表达（承接裁决 21）

### 5.1 方案：用「材质与工艺」编码，不用「数量」

五级由**"这条字是用什么留下来的"**承载。玩家能区分五级，但**数不出级**——这正是裁决 21 要的。

| urgency | 语言标签（S7 §3.1） | 载体介质（非可数） | 板面状态 | 附加物（剪影/夜间可读） |
|---|---|---|---|---|
| 1 | 还行 | **折角的纸片**，塞在板缝里 | 板面完整 | 无 |
| 2 | 明天紧 | **炭笔**写在板面，边缘被雨晕开 | 板面完整 | 无 |
| 3 | 今天就要 | **刀刻**进木头，木屑还在刻痕边 | 刻痕处板面被划破 | 无 |
| 4 | 有人在挨 | **赭红颜料**写在板上，**压住旧字**（旧字被擦花） | 板面被反复擦出毛面 | 板边挂一只**空杯** |
| 5 | 已经在死 | **钉上去的一块木牌**，字是烙/凿的，牌下钉着死者的一件东西 | 该处板面**被刨掉一层**（凹陷，有厚度） | 牌上挂一件**实物**（空瓶/弹壳/一只鞋） |

**单射性说明**：介质 ∈ {纸片, 炭, 刻, 赭红覆盖, 加钉木牌} 已是 5 个互异值 → 与 `urgency 1–5` 单射；板面状态 ∈ {完整, 划破, 擦毛, 刨凹} 与附加物 ∈ {无, 空杯, 实物} 提供两级冗余。**没有任何一级是靠"有几个单位"表达的**（没有 ★、没有 ▮▮▮、没有刻度、没有进度条）。

**明度校验**：纸片 L\*≈80（最轻）· 炭 L\*≈22 · 刻痕（无颜料，靠投影，ΔL\*≈25）· 赭红 L\*≈45（且**叠在炭字上**，两种介质同现）· 木牌 L\*≈55（且有厚度投影）。任意相邻两级 ΔL\* ≥ 18，满足 §2.2。

### 5.2 关于 S7 已写的「u4/u5 红标」

S7 §3.1 允许 u4/u5 使用红标。本份**不删除它，但降级它为冗余**：红色只是赭红颜料与烙痕的自然结果；**真正的判据是"板面被改造了"与"板边挂了东西"**。色盲玩家关闭色相后仍可区分（介质 + 附加物 + 厚度投影）。→ 需 S5/S7/S9 确认（§10-4）。

### 5.3 板上那句话

S7 已给五句世界侧短句（"今晚有人要空着杯子睡"）。**句子是主通道，介质是冗余**。二者同现，任何一条单独成立都能读出紧迫度。

## 6. 字幕、偷听与长文本

### 6.1 通用文本可读性下限

| 项 | 规格 | 级别 |
|---|---|---|
| 行宽 | ≤ **42 全角字符**（超过即换行；行长过长会破坏回扫） | Basic |
| 字号 | 1.00×（默认 20px @1080p）– **2.00×** 连续可调 | Standard |
| 行距 / 段距 | 1.5 / 1.5 段 | Basic |
| 底板 | 对比比 **≥ 4.5:1 对任意背景**；实现为"背景暗化 + 文字亮化"，**不用纯黑遮罩**（遮罩是 Sensation 且压画面信息）；α 可调 0–1.00，默认 0.70 | Basic |
| 同时行数 | ≤ 2 行 | Basic |
| 说话者标识 | **形状名签**（§2.1 的 glyph，取该 NPC 的 `homePost` 对应形状）+ 名字；**颜色不作唯一判据**（glyph + 字重差 + 固定侧位三重） | Basic |
| 1060 成本 | 引擎 UI 层，**< 0.15 ms**（文本是 2D，本作文本量对 1060 无压力）。✅ | |

### 6.2 长自白（Black Isle 式）

- **无时限**：不自动翻页、不倒计时、不因玩家慢读而跳过。（Basic）
- **可回看**：已读段落可回滚；已读段落以**明度降低 15%** 标记，**且仍满足 4.5:1 地板**（不能灰到读不出）。（Comprehensive）
- **世界继续跑**：阅读时世界**不暂停**（P3）。阅读无时限 ≠ 世界停下；代价照常发生。→ §10-2 待裁决是否提供 0.25× 减速。
- **不做**：打字机音效逐字吐字作为默认（可选项）；全屏暗化演出；配音口型特写。全部属 Sensation 或认知负担。

### 6.3 偷听到的碎句（gossip overhear）—— D4 的关键信息通道

**三层保真**（由距离与遮挡的**几何**决定，非随机——遵守"零随机"纪律）：

| 条件 | 呈现 |
|---|---|
| 6–10 m，无遮挡 | 全句 |
| 10–16 m，或有遮挡 | 缺 1–2 个词，用 `……` 占位 |
| > 16 m | 只剩"墙那边有两个人在说话"，可能漏出一个名字 |

**规则**

1. **偷听不进字幕主队列**，进独立的"耳边的字"层：**斜体 + 无名签**（名签为**空环**：只有底盘没有 glyph = "你不知道是谁"）。这是 §2.1 底盘规则的复用，零新增概念。
2. **必进日志**（Standard 起）："听来的话"按 `dayKey` 分组，保留 **7 日**（与 `MEMORY_SHORT_DAYS = 7` 对齐），可搜索、可回看。→ 保护**读**：gossip 是 D4 的唯一入口，丢一句等于断一条链。
3. **补全选项**（Standard）：开启后，范围内全部 gossip 以**全句入日志**（不进屏幕，避免刷屏），距离保真层对日志失效。
4. **保真缺失不是随机**：用确定性键（距离档 × 遮挡档），保证 `--dump-gossip` 可复现"玩家听到了什么"。
5. 1060 成本：文本，≈0。✅

### 7.2 抗锯齿策略（与绊线可读性的直接冲突）

**决定：默认 FXAA，默认关闭 TAA。** 理由：TAA 的时域累积会把 `SET_TRAP` 的 1px 绊线糊掉或闪烁——而绊线是本作**判读后果最重**的一条世界信号。若必须开 TAA，则信号层需做**屏幕空间最小宽度钳制（≥1.5px）+ 关闭该层的抖动**。→ 需程基岩确认（§10-5）。

同时默认关闭：SSAO（改用手绘 AO 贴图，更可控也更便宜）、SSR、DOF、体积雾、动态分辨率骤变。**这些关闭不损失任何信息通道，且都属 Sensation。**

### 7.3 画质降级时**不可被关闭**的表现层通道（因为它们承载核心动词）
